# SPECTRA: Единая мастер-спецификация, математическая модель и 48-уровневый аудит полноты самообучения

## ЧАСТЬ I. КОНЦЕПТУАЛЬНОЕ ЯДРО И ТРЕХКОНТУРНАЯ АРХИТЕКТУРА

### 1.1. Фундаментальная проблема и смена парадигмы

Современные агентные ИИ-системы разделены на два полярных класса, каждый из которых обладает критическим изъяном:

1. **Жесткие детерминированные пайплайны (DAG / Конечные автоматы):** предсказуемы, дешевы и проверяемы, но хрупки — любая непредвиденная ошибка API, изменение формата данных или нестандартный граничный случай приводят к полному отказу выполнения.

2. **Автономные ReAct-агенты (бесконтрольный цикл LLM):** гибки и способны обходить препятствия, но страдают от стохастического дрейфа, галлюцинаций, зацикливания, непредсказуемой задержки и отсутствия долгосрочной памяти об исправленных ошибках.

Большинство существующих гибридных архитектур ограничиваются **самовосстановлением в рантайме (Runtime Self-Healing)**: исправив сбой в рамках одной сессии, система «забывает» найденное решение и в следующей сессии тратит ресурсы на решение той же проблемы с нуля.

**Идея Spectra** заключается в синтезе надежности графовых автоматов и адаптивности нейросетей в рамках **непрерывно самообучающейся архитектуры (Continual Self-Learning System)**:

* **Граф как исполняемый код:** программа представлена ориентированным графом с типизированными узлами, единым объектом состояния (`State`) и детерминированными предикатами переходов (`guard`).

* **Изоляция стохастичности:** генеративные модели вызываются строго внутри типизированных узлов или в момент структурного сбоя (тупика), но не управляют маршрутизацией вслепую.

* **Полная 48-уровневая эволюция и амортизированная устойчивость по Ляпунову:** система обучается во всех измерениях — от ортогональных адаптеров векторного пространства с тихоновским якорем, весов модальностей, промптов, митоза перегруженных узлов и каскадных уровней моделей внутри `llm`-узлов, символьных признаков $\psi^*(s)$, каузального одеяла Маркова $\mathcal{MB}(v_t, G)$ и контрфактически безопасной очистки контрактов чтения $R(v)$ до политики мета-арбитра System-2, локального арбитра System-1, топологии графа, пушаут-слияния, предикатной бифуркации и бисимуляционной свертки конкурентных веток, транзитивной абстрактной интерпретации `guard`-путей, контрактов `check`, схемы данных `State` ($\mathcal{K}_t$) со сжатием путей алиасов, индукции Saga-компенсаторов $\Phi_v^{-1}$, CEGIS-патчинга кода инструментов, кросс-задачной мета-инициализации графов с синтезом морфизмов подтипов Лисков, ретроактивной коррекции отложенного аудита $Y_{\text{ext}}$, лагранжевой адаптации теневых цен ресурсов и гарантии глобальной сходимости через многошаговую функцию Ляпунова.

### 1.2. Трехконтурная когнитивная архитектура

Жизненный цикл управления и обучения в Spectra разделен на три контура с различным масштабом времени и вычислительной стоимости:

#### Контур 1: Fast Loop (Исполнительный уровень — миллисекунды)

Отвечает за штатное продвижение задачи по текущему графу (или мета-синтезированному стартовому графу $G_0^*$ для нового класса задач).

* **Типизированные узлы:**

  * `llm` — вызов языковой модели со строгой валидацией выходной схемы, эволюционирующим банком внутриузловых Few-Shot примеров, автоматическим митозом при избыточной энтропии схемы выхода и адаптивным каскадным выбором ранга модели ($\text{frontier} \to \text{light} \to \text{local\_slm}$);

  * `tool` — вызов детерминированного внешнего или локального инструмента из реестра `ToolRegistry` с поддержкой версионирования AST-кода, верифицированных Saga-компенсаторов отката и кэшированных адаптеров приведения типов ($v_{\text{coerce}}$);

  * `branch` / `join` — параллельное разветвление и синхронизация потоков исполнения (включая автоматически обнаруженные независимые цепочки после каузальной очистки контрактов чтения с учетом квот внешних API);

  * `check` — проверка инвариантов состояния (контрактный ассерт, чьи предикаты индуцируются по мере накопления опыта);

  * `macro` — инкапсулированный подграф (включая рекурсивные макроноды произвольной глубины), дистиллированный из успешного прошлого опыта и поддерживающий прозрачное разворачивание стека (`unfold`) при внутреннем сбое;

  * `fused` — скомпилированная цепочка последовательных детерминированных инструментов, выполняемая за один шаг без промежуточных транзакций в БД.

* **Детерминированная маршрутизация:** переходы между узлами управляются булевыми предикатами (`guard`) над объектом `State` с фиксированными приоритетами и гарантированным дефолтным переходом (`fallback`), что полностью исключает гонку условий и неполноту ветвления.

#### Контур 2: Slow Loop (Мета-уровень восстановления — секунды)

Активируется исключительно при возникновении **тупика (Deadlock)** в Fast Loop: когда ни один `guard` не сработал, обнаружено зацикливание состояния, провалена проверка `check`, возникла ошибка инструмента или исчерпан лимит шагов. Восстановление опирается на двухуровневый когнитивный арбитраж:

1. **Поиск в памяти прецедентов и реляционная адаптация (Experience Replay & Grounding):** по составному изометрически выровненному вектору тупика (ошибка $+$ локальная топология по каузальному одеялу Маркова $\mathcal{MB}(v_t, G)$ $+$ каузально отфильтрованная схема состояния) из векторного хранилища извлекаются проверенные рецепты исправления и антипаттерны с учетом нестационарного дисконтирования устаревшей статистики (CUSUM), взвешенного по калибровочной надежности критика. Оператор реляционного заземления $\Psi_{\text{adapt}}$ привязывает старый рецепт к новым узлам внутри каузального одеяла Маркова через совпадение их канонизированных контрактов чтения/записи.

2. **Арбитр System-1 (`@receptron/laya` на базе ONNX Runtime):** быстрая локальная модель принятия решений ($\sim 100\text{--}150\text{ мс}$ на CPU, $0$ платных токенов). Выполняет две функции:

   * выбирает готовый рецепт из памяти прецедентов, если найден кандидат с высокой степенью уверенности;

   * оценивает риск структурного дрейфа, связность с целью и необходимую глубину отката (`keep`, `rollback_last`, `rollback_session`) для любой предлагаемой мутации.

3. **Арбитр System-2 (LLM с эволюционирующей мета-политикой):** вызывается только тогда, когда в памяти нет готового решения. Выбирает оптимальный оператор мутации из нестационарного мета-распределения Томпсона $\pi_{\text{meta}}$ (`addNode`, `addEdge`, `rewire`, `pruneNodes`, `injectMacro`, `registerTool`, `patchToolAST`, `introduceStateKey`, `splitNode`) на основе диагностики тупика и семантически отфильтрованного каталога инструментов.

4. **Статический гейткипер детерминизма, транзитивной выполнимости путей и конкурентного слияния:** перед тем как мутированный граф вернется в Fast Loop, алгоритм проверяет отсутствие тупиковых циклов, топологическую и многошаговую семантическую (через прямую абстрактную интерпретацию интервалов) достижимость цели, детерминизм приоритетов, а также алгебраическую коммутативность (Pushout-слияние или предикатную 3-way бифуркацию) с параллельными мутациями других активных сессий.

#### Контур 3: Consolidation Loop («Фаза сна» — фоновый режим)

Асинхронный контур долгосрочного самообучения и гигиены графа, работающий поверх накопленных логов траекторий с разделением скоростей обучения (Two-Timescale Stochastic Approximation):

1. **Дистилляция, рекурсивная иерархия, эволюция макронод и типобезопасный кросс-графовый синтез с реестром морфизмов схем:** строит обратный срез по данным от целевых переменных `State` к точке тупика, отсекает побочные ветви, выводит строгий контракт входов/выходов, упаковывает подграф в переиспользуемую `MacroNode` (уровня $l \to l+1$) и использует библиотеку макронод и выученных морфизмов приведения типов $\mathcal{M}_{\text{coerce}}$ для Zero-Shot сборки новых графов $G_0^*$ с проверкой потокового подтипирования Лисков ($\preceq_{\text{sub}}$).

2. **Дважды робастная конформная оценка (WC-LCB-DR-OPE), ретроактивная поправка аудита, лагранжева адаптация цен ресурсов, калиброванный CUSUM и Coreset-сжатие памяти:** распределяет итоговую полезность сессии между несколькими мутациями (TD-кредит), ретроактивно корректирует исторические оценки прецедентов при поступлении отложенных меток аудита $Y_{\text{ext}}$, обновляет двойственные множители Лагранжа (теневые цены токенов, времени и лимитов API), устраняет выживаемостное смещение оценок через дважды робастный конформный оценщик со взвешиванием ковариатного сдвига, экспоненциально дисконтирует старые счетчики при детекции сдвига среды (CUSUM с защитой от раскачки некалиброванным критиком) и сжимает дубликаты через взвешенный по полезности субмодулярный Coreset.

3. **Мета-калибровка System-1, изометрическое выравнивание эмбеддингов с якорем Тихонова, эволюция System-2 и парная CRN-SPSA настройка гиперпараметров:** обновляет температуру калибровки $T_{\text{cal}}$, пороги допуска $\boldsymbol{\tau}$, проекционный адаптер `@receptron/laya`, веса модальностей $(\alpha, \beta, \gamma)$, параметр затухания каузального одеяла Маркова $\alpha_{\text{ppr}}^*$, ортогональную матрицу выравнивания пространства представлений $R_{\text{emb}} \in \text{SO}(d)$ с регуляризацией Фробениуса, а также обучает стратегию синтеза мутаций System-2 и адаптирует мета-гиперпараметры фазы «Сна» методом парных антитетических возмущений (CRN-SPSA) с пониженной дисперсией.

4. **Внутриузловая эволюция промптов, митоз узлов, каскадное понижение ранга моделей, CEGIS-ремонт кода тулов, индукция Saga и `check`-узлов, контрфактически безопасная очистка контрактов** $R(v)$**, признаки** $\psi^*(s)$ **и схема** $\mathcal{K}_t \to \mathcal{K}_{t+1}$**:** обновляет инструкции и Few-Shot примеры внутри `llm`-узлов, расщепляет когнитивно перегруженные `llm`-узлы (митоз), переводит стабилизировавшиеся `llm`-узлы на более легкие модели ($\text{frontier} \to \text{light} \to \text{local\_slm}$), автоматически патчит AST-код упавших инструментов по контрпримерам $\mathcal{S}_{\text{test}}^{(t+1)}$, индуцирует и верифицирует компенсирующие операторы отката $\Phi_v^{-1}$, очищает контракты чтения $R(v)$ от ложных корреляций через верхнюю доверительную границу условной взаимной информации ($\text{CMI}_{\text{UCB}}$) и контрфактическое зондирование, синтезирует ранние `check`-узлы, индуцирует символьные функции признаков $\psi^*(s)$ для `guard`-условий и эволюционирует словарь ключей состояния со сжатием транзитивных цепочек алиасов (Union-Find) и сборкой мусора в карантине $\mathcal{K}_{\text{staging}}$.

5. **Компиляторный рефакторинг, бисимуляционная свертка веток, активное любопытство и амортизированный фильтр Ляпунова:** выполняет оптимизационные проходы (*Pruning*, *Linear Fusion*, *Quota-Aware Auto-Parallelization*, *Bisimulation Quotienting*, *Determinization*, *Plasticity Unfreeze*), генерирует граничные задачи в зонах максимальной эпистемической неопределенности и фиксирует глобальное обновление системы при выполнении амортизированного условия диссипативности Ляпунова.

### 1.3. Системные инварианты Spectra

1. **Иммутабельность истории, коммутативное слияние / бифуркация и откат первого класса:** любая мутация графа порождает новую версию в append-only журнале со структурным хэшем; параллельные ветки мутаций объединяются через бесконфликтный графовый Pushout или предикатную 3-way бифуркацию с последующей бисимуляционной сверткой, а возврат к предшествующей версии сопровождается вызовом верифицированных компенсирующих Saga-операторов $\Phi_v^{-1}$ для неидемпотентных инструментов (или остановкой перед барьером необратимости $\text{Barrier}(v) = 1$).

2. **Ограниченный топологический и многошаговый семантический детерминизм (Bounded Determinism):** стохастичность допускается внутри вычислений узла, но топология маршрутизации обязана быть свободной от коллизий приоритетов, бесконечных циклов без выхода и транзитивно несовместимых цепочек `guard`-предикатов любой длины.

3. **Песочница динамического кода:** инструменты и узлы-коэрсеры схем, синтезированные или пропатченные через CEGIS в рантайме (`registerTool`, `patchToolAST`, `synthCoercer`), исполняются в изолированном виртуальном контексте `node:vm` со строгим лимитом времени ($\le 250\text{ мс}$) и полным запретом доступа к файловой системе, сети и процессу ОС.

4. **Двойной гейткипинг качества:** ни одна мутация не попадает в рантайм без прохождения нейросетевого фильтра дрейфа (System-1) и графового верификатора (Tarjan SCC $+$ Reverse BFS $+$ Transitive Abstract Interval Check).

5. **Амортизированная монотонность эволюции и двухуровневая защита от взлома награды (Anti-Reward Hacking):** рефакторинг графа, новые ключи схемы и новые навыки принимаются только при соблюдении многошагового условия диссипативности Ляпунова $\Delta \mathcal{V}_{\text{Lyap}} \le -\delta_{\text{lyap}}$, а семантический критик калибруется по внешнему отложенному сигналу валидности $Y_{\text{ext}}$ с ретроактивным пересчетом кредита прошлых мутаций.

## ЧАСТЬ II. МАТЕМАТИЧЕСКИЙ АППАРАТ СИСТЕМЫ

### 2.1. Формальная модель графа, кросс-задачного синтеза, конкурентного слияния и эволюционирующего состояния

#### Определение 1 (Исполняемый граф Spectra)

Ориентированный мультимодальный граф системы определяется кортежем:

$$
G = (V, E, v_{\text{start}}, V_{\text{goal}}, \mathcal{T}, \Gamma, \Pi)
$$

где:

* $V$ — конечное непустое множество вершин (узлов), $\vert V\vert = n$;

* $E \subseteq V \times V$ — множество ориентированных ребер, $\vert E\vert = m$;

* $v_{\text{start}} \in V$ — единственная входная вершина графа;

* $V_{\text{goal}} \subset V, V_{\text{goal}} \neq \emptyset$ — подмножество терминальных (целевых) вершин;

* $\mathcal{T}: V \to \{\text{llm}, \text{tool}, \text{branch}, \text{join}, \text{check}, \text{macro}, \text{fused}\}$ — функция типизации вершин;

* $\Gamma: E \to (\mathcal{S} \to \{0, 1\})$ — отображение каждого ребра $e \in E$ в вычислимый булев предикат (`guard`) над пространством состояний $\mathcal{S}$;

* $\Pi: E \to \mathbb{N}$ — функция приоритета ребер, задающая строгий порядок проверки переходов.

#### Определение 1а (Типобезопасный кросс-задачный мета-синтез стартового графа и реестр морфизмов приведения схем $\mathcal{M}_{\text{coerce}}$)

При поступлении нового класса задач с вектором намерения $\mathbf{v}_{\text{intent}} \in \mathbb{R}^d$, начальным набором доступных ключей $K_{\text{init}} \subseteq \mathcal{K}_t$, целевыми ключами $K_{\text{goal}} \subseteq \mathcal{K}_t$ и верхним бюджетом стоимости инициализации $C_{\text{init\_max}} > 0$ оператор $\text{MetaInit}(\mathbf{v}_{\text{intent}}, K_{\text{init}}, K_{\text{goal}})$ строит стартовый ориентированный ациклический граф $G_0^*$ из накопленной библиотеки макронод и инструментов $\mathcal{L}_{\text{skills}} = \mathcal{M}_{\text{macro}} \cup \mathcal{R}_{\text{core}}$ путем решения задачи целочисленного потокового покрытия контрактов минимальной ожидаемой стоимости:

$$
G_0^* = \arg\min_{G_{\text{dag}} \subseteq \mathcal{L}_{\text{skills}}} \sum_{u \in V(G_{\text{dag}})} \left( \frac{\mathbb{E}[\text{Cost}(u)]}{C_{\text{conf}}(u) \cdot \max\big(\epsilon, \, \sigma_{\text{cos}}(R_{\text{emb}}\mathbf{v}_{\text{intent}}, \mathbf{v}_u)\big)} \right) + \Omega(G_{\text{dag}})
$$

Чтобы исключить ошибки несовместимости форматов данных на стыках макронод из разных доменов, помимо теоретико-множественного покрытия имен ключей вводится **инвариант структурного подтипирования Лисков по JSON-схемам (**$\preceq_{\text{sub}}$**)** и **обучаемый реестр морфизмов приведения типов** $\mathcal{M}_{\text{coerce}}$:

1. Если выходной домен поставщика является подтипом входного домена потребителя ($\text{Dom}_{\text{out}}(w, k) \preceq_{\text{sub}} \text{Dom}_{\text{in}}(u, k)$), ребро $(w, u)$ соединяется напрямую.

2. Если прямое отношение подтипа нарушено ($\text{Dom}_{\text{out}}(w, k) \not\preceq_{\text{sub}} \text{Dom}_{\text{in}}(u, k)$), система ищет или синтезирует через CEGIS детерминированный морфизм-коэрсер $\Phi_{\text{coerce}} \in \mathcal{M}_{\text{coerce}}\big(\text{Dom}_{\text{out}}(w, k) \to \text{Dom}_{\text{in}}(u, k)\big)$, верифицированный на множестве граничных значений выходной схемы поставщика $\text{Dom}_{\text{bound}}\big(\text{Dom}_{\text{out}}(w, k)\big)$:

$$
\forall x \in \text{Dom}_{\text{bound}}\big(\text{Dom}_{\text{out}}(w, k)\big): \quad \Big(\text{err}\big(\Phi_{\text{coerce}}(x)\big) = \varnothing\Big) \land \Big(\Phi_{\text{coerce}}(x) \in \text{Dom}_{\text{in}}(u, k)\Big)
$$

Верифицированный морфизм $\Phi_{\text{coerce}}$ кэшируется в библиотеке $\mathcal{M}_{\text{coerce}}$ по паре структурных хэшей схем $\big(H(\text{Dom}_{\text{out}}), H(\text{Dom}_{\text{in}})\big)$ для мгновенного $O(1)$ переиспользования в будущих задачах и инжектируется как типизированный узел-адаптер $v_{\text{coerce}}$ между $w$ и $u$:

$$
K_{\text{goal}} \subseteq K_{\text{init}} \cup \bigcup_{u \in V(G_{\text{dag}})} W(u), \quad \forall u \in V(G_{\text{dag}}), \forall k \in R(u): \exists w \prec_{G_{\text{dag}}} u \text{ с } k \in W(w) \land \Big(\text{Dom}_{\text{out}}(w, k) \preceq_{\text{sub}} \text{Dom}_{\text{in}}(u, k) \lor \exists \Phi_{\text{coerce}} \in \mathcal{M}_{\text{coerce}}\Big), \quad \sum_{u \in V(G_{\text{dag}})} \mathbb{E}[\text{Cost}(u)] \le C_{\text{init\_max}}
$$

#### Определение 1б (Алгебраический Pushout, предикатная 3-Way бифуркация и бисимуляционная свертка)

Пусть две параллельные сессии стартовали от общей базовой версии графа $G_0 = (V_0, E_0)$ и в результате разрешения независимых тупиков породили две мутированные ветки $G_A = m_A(G_0)$ и $G_B = m_B(G_0)$ с множествами затронутых вершин $\Delta V_A, \Delta V_B$ и модифицированными контрактами $(R_A, W_A), (R_B, W_B)$.

1. **Бесконфликтный графовый Pushout (**$\text{Commute}(m_A, m_B) = 1$**):** мутации называются алгебраически коммутативными, если их структурные окрестности и потоки записи не конфликтуют:

   $$
   \text{Commute}(m_A, m_B) \iff \big(\Delta V_A \cap \Delta V_B = \emptyset\big) \land \big(W_A \cap (R_B \cup W_B) = \emptyset\big) \land \big(W_B \cap (R_A \cup W_A) = \emptyset\big)
   $$

   При $\text{Commute}(m_A, m_B) = 1$ и $\mathcal{V}(G_A \oplus_{G_0} G_B) = \text{PASS}$ формируется объединенный граф (категорный Pushout $G_0 \hookrightarrow G_A, G_0 \hookrightarrow G_B$):

   $$
   G_{AB} = G_A \oplus_{G_0} G_B = \Big( V_0 \cup (V_A \setminus V_0) \cup (V_B \setminus V_0), \; (E_0 \setminus (E_A^- \cup E_B^-)) \cup E_A^+ \cup E_B^+ \Big)
   $$

2. **Предикатная 3-Way бифуркация при коллизии в узкой вершине (Guarded Bifurcation on Non-Commutative Hotspot):** если обе мутации модифицируют одну и ту же «горячую» вершину $v_{\text{hot}} \in \Delta V_A \cap \Delta V_B$, но срабатывают на дизъюнктных предикатах входа в тупик ($\forall s \in \mathcal{S}_{\text{hist}}: \Gamma_A(s) \cdot \Gamma_B(s) = 0$), вместо отбрасывания одной из веток создается предикатная развилка из $v_{\text{hot}}$:

   $$
   \text{Out}_{\text{merged}}(v_{\text{hot}}) = \big\{ e_A = (v_{\text{hot}}, u_A) \text{ с } \Gamma_A, \Pi(e_A)=1 \big\} \cup \big\{ e_B = (v_{\text{hot}}, u_B) \text{ с } \Gamma_B, \Pi(e_B)=2 \big\} \cup \text{Out}_{\text{fallback}}(v_{\text{hot}})
   $$

   Если же пересекаются и сами предикаты ($\exists s: \Gamma_A(s) = \Gamma_B(s) = 1$), побеждает ветка с большей ожидаемой полезностью $\Delta U$, а вторая отправляется на реляционный ребейз $\widetilde{m}_B = \Psi_{\text{adapt}}(m_B, G_A, v_t)$.

3. **Обратная бисимуляционная свертка ветвлений (Bisimulation E-Graph Quotienting):** чтобы после серии предикатных бифуркаций граф не вырождался в экспоненциально раздутое дерево с дублирующимися подпутями, в фазе «Сна» над вершинами параллельных веток $u_a, u_b \in V$ вводится отношение **функциональной бисимуляции** $u_a \sim_{\text{bisim}} u_b$:

   $$
   u_a \sim_{\text{bisim}} u_b \iff \big(R(u_a) = R(u_b)\big) \land \big(W(u_a) = W(u_b)\big) \land \Big(\forall s \in \mathcal{S}_{\text{test}}^{(t+1)}: \Phi_{u_a}(s) = \Phi_{u_b}(s)\Big) \land \Big(\text{Out}(u_a) / {\sim_{\text{bisim}}} = \text{Out}(u_b) / {\sim_{\text{bisim}}}\Big)
   $$

   Классы эквивалентности $[u]_{\sim_{\text{bisim}}}$ склеиваются в одну каноническую вершину ромбовидного графа $G / {\sim_{\text{bisim}}}$ (DAG Diamond Folding), а параллельные входящие ребра из одного источника объединяются по дизъюнкции предикатов $\Gamma_{\text{merged}}(s) = \Gamma_a(s) \lor \Gamma_b(s)$.

#### Определение 2 (Эволюционирующее пространство состояний $\mathcal{K}_t$, индукция Saga-компенсаторов $\Phi_v^{-1}$ и сжатие путей онтологии)

Пусть $\mathcal{K}_t = \{k_1, k_2, \dots, k_{D_t}\}$ — словарь типизированных ключей данных на эпохе эволюции $t$, где каждый ключ $k \in \mathcal{K}_t$ имеет строгую JSON-схему домена $\text{Dom}(k)$ и семантический эмбеддинг описания $\mathbf{e}_k \in \mathbb{R}^d$. Состояние системы представляет собой частичное отображение $s_t \in \mathcal{S}_t$.
Каждой вершине $v \in V$ сопоставлены:

* множество читаемых ключей $R(v) \subseteq \mathcal{K}_t$ и множество модифицируемых ключей $W(v) \subseteq \mathcal{K}_t$;

* вектор потребления внешних лимитируемых ресурсов $\text{Res}(v) \in \mathbb{R}_+^Q$ (RPS к внешним API, пул соединений БД, лимит токенов в минуту);

* оператор трансформации состояния $\Phi_v: \mathcal{S}_t \to \mathcal{S}_t \times \mathcal{E}_{\text{err}}$, изменяющий только ключи из $W(v)$;

* класс побочных эффектов $\text{Idemp}(v) \in \{\text{pure}, \text{idempotent}, \text{non\_idempotent}\}$.

**Автоматический синтез и верификация компенсирующих Saga-операторов (**$\text{SynthSaga}$**):** для каждой вершины с $\text{Idemp}(v) = \text{non\_idempotent}$ при ее регистрации или мутации арбитр синтезирует парный компенсирующий оператор $\Phi_v^{-1}: \mathcal{S}_t \to \mathcal{S}_t$, который проверяется в `Shadow Sandbox` на регрессионном пуле $\mathcal{S}_{\text{test}}^{(t+1)}(v)$ по критерию обратимости состояния:

$$
\mathcal{E}_{\text{saga}}(\Phi_v^{-1}) = \frac{1}{\vert\mathcal{S}_{\text{test}}^{(t+1)}(v)\vert} \sum_{s \in \mathcal{S}_{\text{test}}^{(t+1)}(v)} \left\| \text{Proj}_{R(v) \cup W(v)}\Big(\Phi_v^{-1}\big(\Phi_v(s)\big)\Big) - \text{Proj}_{R(v) \cup W(v)}(s) \right\|_1 \le \epsilon_{\text{saga}}
$$

Если условие $\mathcal{E}_{\text{saga}}(\Phi_v^{-1}) \le \epsilon_{\text{saga}}$ выполнено, откат на $k$ шагов формализуется суперпозицией обратных операторов:

$$
\text{Rollback}(\tau_t, k) = \left( \bigcirc_{j=t}^{t-k+1} \Phi_{v_j}^{-1} \right)(s_t) \mapsto s_{t-k}
$$

Если же для внешнего действия невозможно синтезировать компенсирующий оператор с ошибкой $\le \epsilon_{\text{saga}}$ (например, отправка внешнего физического уведомления), вершине автоматически присваивается **барьер необратимости** $\text{Barrier}(v) = 1$, и глубина любого последующего отката жестко ограничивается моментом последнего барьера: $t - k \ge \max\{j \le t \mid \text{Barrier}(v_j) = 1\}$.

**Оператор онтологического расширения, дедупликации схемы и сжатие транзитивных алиасов (**$\text{SchemaEvolve}$**,** $\text{SchemaMerge}$ **&** $\text{UnionFindGC}$**):**

1. *Промоушен ключа:* если при разрешении тупика арбитр System-2 вводит новый промежуточный ключ $k_{\text{new}} \notin \mathcal{K}_t$, он помещается в карантин $\mathcal{K}_{\text{staging}}$ и переводится в каноническую онтологию $\mathcal{K}_{t+1} = \mathcal{K}_t \cup \{k_{\text{new}}\}$ в фазе «Сна» тогда и только тогда, когда его условный информационный выигрыш положителен и он входит в минимальный каузальный срез $V_{\text{slice}}^*$:

   $$
   \text{PromoteKey}(k_{\text{new}}) \iff \Big( I(\text{goal}; \, k_{\text{new}} \mid R(u_{\text{prod}})) > \theta_{\text{IG}} \Big) \land \Big( \exists v \in V_{\text{slice}}^* : k_{\text{new}} \in R(v) \Big)
   $$

2. *Слияние синонимичных ключей и сжатие цепочек алиасов (Union-Find Path Compression & Staging GC):* если два ключа $k_a, k_b \in \mathcal{K}_t$ имеют изоморфные JSON-схемы ($\text{Dom}(k_a) \cong \text{Dom}(k_b)$), высокую семантическую близость и высокую нормированную взаимную информацию на исторических траекториях:

   $$
   \text{MergeKeys}(k_a, k_b) \iff \big(\langle \mathbf{e}_{k_a}, \mathbf{e}_{k_b} \rangle \ge \theta_{\text{syn}}\big) \land \left( \frac{I(k_a; k_b)}{\min\big(H(k_a), H(k_b)\big)} \ge \theta_{\text{syn}} \right)
   $$

   то для исключения многошаговых транзитивных цепочек ($k_c \mapsto k_b \mapsto k_a$) и циклов переименования над лесом алиасов применяется оператор **сжатия путей Тарьяна (**$\text{FindCanonical}$**)** с лексикографически-возрастным выбором корня:

   $$
   \text{Alias}(k) \gets \text{FindCanonical}(k) = \arg\min_{k' \in [k]_{\sim_{\text{syn}}}} \text{CreatedAt}(k')
   $$

   При этом карантинные ключи $k_{\text{stg}} \in \mathcal{K}_{\text{staging}}$, не набравшие порог промоушена $\theta_{\text{IG}}$ за горизонт жизни $T_{\text{staging\_ttl}}$ эпох «Сна», автоматически удаляются сборщиком мусора ($\text{EvictStaging}$), предотвращая зашумление векторного представления схемы $\hat{\mathbf{e}}_{\text{schema}}$.

#### Определение 2а (Контрфактически безопасная каузальная очистка контрактов чтения — UCB-CMI & Counterfactual Read Deflation)

При синтезе узлов (особенно типа `llm`) их входной контракт $R(v)$ часто оказывается избыточным: узел декларирует чтение широкого подмножества ключей состояния, хотя фактически его выход $W(v)$ зависит лишь от малой части из них. Однако наивное удаление ключа по точечной эмпирической оценке $\widehat{\text{CMI}}(k \to v) < \epsilon_{\text{cmi}}$ несет фатальный риск ампутации **редких триггерных (хвостовых) ключей** (например, флага аварийного режима, который равен $0$ в $99\%$ запусков и меняет поведение узла только при редком значении $1$).

Поэтому в фазе «Сна» для каждой вершины $v \in V$ и каждого заявленного ключа $k \in R(v)$ на выборке из $N(v) \ge N_{\text{cmi}}$ исполнений вычисляется **верхняя доверительная граница условной взаимной информации (**$\text{CMI}_{\text{UCB}}$**)** совместно с **интервенционной контрфактической чувствительностью (**$\text{Sens}_{\text{cf}}$**)** в `Shadow Sandbox`:

$$
\text{CMI}_{\text{UCB}}(k \to v) = \widehat{I}\big(W(v); \, k \;\big|\; R(v) \setminus \{k\}\big) + c_{\text{cmi}} \sqrt{\frac{\ln N(v)}{N_{\text{eff}}(k, v) + 1}}, \quad \text{Sens}_{\text{cf}}(k \to v) = \max_{s \in \mathcal{S}_{\text{test}}^{(t+1)}(v), \, k' \in \text{Dom}_{\text{bound}}(k)} \left\| \Phi_v(s) - \Phi_v\big(s[k \gets k']\big) \right\|_1
$$

где $N_{\text{eff}}(k, v)$ — эффективное число наблюдений нетривиальных (миноритарных) значений ключа $k$, а $\text{Dom}_{\text{bound}}(k)$ — граничные значения JSON-схемы ключа $k$. Оператор редукции контракта удаляет ключ $k$ из $R(v)$ тогда и только тогда, когда одновременно малы и верхняя статистическая граница, и контрфактическая чувствительность:

$$
R^{(t+1)}(v) = R^{(t)}(v) \setminus \Big\{ k \in R^{(t)}(v) \;\Big|\; \big(\text{CMI}_{\text{UCB}}(k \to v) < \epsilon_{\text{cmi}}\big) \land \big(\text{Sens}_{\text{cf}}(k \to v) = 0\big) \Big\}
$$

#### Определение 3 (Детерминированный оператор маршрутизации)

Для текущей вершины $v_t \in V \setminus V_{\text{goal}}$ и состояния $s_t \in \mathcal{S}_t$ множество активных исходящих ребер определяется как:

$$
E_{\text{active}}(v_t, s_t) = \{e = (v_t, u) \in E \mid \Gamma(e)(s_t) = 1\}
$$

Если $E_{\text{active}}(v_t, s_t) \neq \emptyset$, следующая вершина выбирается однозначно по минимуму численного индекса приоритета:

$$
e^* = \arg\min_{e \in E_{\text{active}}(v_t, s_t)} \Pi(e), \quad v_{t+1} = \text{target}(e^*)
$$

#### Определение 4 (Формальный предикат тупика — Deadlock Condition)

Траектория выполнения длины $t$ есть последовательность $\tau_t = \langle (v_0, s_0), (v_1, s_1), \dots, (v_t, s_t) \rangle$. Система переходит из Fast Loop в Slow Loop на шаге $t$, если истинен предикат тупика $\mathcal{D}(\tau_t) = 1$, определяемый дизъюнкцией пяти ортогональных условий:

$$
\mathcal{D}(\tau_t) = \mathcal{D}_{\text{stall}} \lor \mathcal{D}_{\text{loop}} \lor \mathcal{D}_{\text{check}} \lor \mathcal{D}_{\text{tool}} \lor \mathcal{D}_{\text{budget}}
$$

где:

1. **Отсутствие валидного перехода (`NO_VALID_TRANSITION`):** $\mathcal{D}_{\text{stall}} \iff (v_t \notin V_{\text{goal}}) \land (E_{\text{active}}(v_t, s_t) = \emptyset)$.

2. **Зацикливание по хэшу состояния (`STATE_HASH_LOOP`):** $\mathcal{D}_{\text{loop}} \iff \sum_{i=0}^{t-1} \mathbb{I}\big(H(v_i, s_i) = H(v_t, s_t)\big) \ge K_{\text{loop}}$.

3. **Нарушение контракта проверки (`CHECK_FAILED`):** $\mathcal{D}_{\text{check}} \iff (\mathcal{T}(v_t) = \text{check}) \land (\text{Assert}_{v_t}(s_t) = 0)$.

4. **Сбой исполнения инструмента (`TOOL_EXECUTION_ERROR`):** $\mathcal{D}_{\text{tool}} \iff \text{err}(\Phi_{v_t}(s_{t-1})) \neq \varnothing$.

5. **Исчерпание жесткого бюджета шагов (`HARD_LIMIT_EXCEEDED`):** $\mathcal{D}_{\text{budget}} \iff t \ge T_{\max}$.

### 2.2. Теория ограниченного детерминизма, транзитивной абстрактной интерпретации путей и статической верификации

Чтобы гарантировать, что мутированный граф $G'$ корректен до его запуска в Fast Loop, вводится формальный верификатор $\mathcal{V}(G')$, проверяющий четыре структурно-семантических инварианта.

#### Инвариант 1 (Локальная детерминированность переходов)

Для любой вершины $v \in V$ и любой пары различных исходящих ребер $e_1, e_2 \in \text{Out}(v)$ ($e_1 \neq e_2$) должно выполняться условие отсутствия коллизии приоритетов:

$$
N_{\text{ambig}}(G) = \sum_{v \in V} \sum_{\substack{e_1, e_2 \in \text{Out}(v) \\ e_1 \neq e_2}} \mathbb{I}\big(\Pi(e_1) = \Pi(e_2)\big) = 0
$$

#### Инвариант 2 (Глобальная ко-достижимость цели — Topological Co-Reachability)

Пусть $V_{\text{reach}}(v_{\text{start}}) \subseteq V$ — множество вершин, достижимых из $v_{\text{start}}$, а $V_{\text{coreach}}(V_{\text{goal}}) \subseteq V$ — множество вершин, из которых существует ориентированный путь хотя бы в одну целевую вершину $v_g \in V_{\text{goal}}$ (Reverse BFS по $G^T$). Граф свободен от топологических тупиков тогда и только тогда, когда:

$$
V_{\text{dead}}(G) = V_{\text{reach}}(v_{\text{start}}) \setminus V_{\text{coreach}}(V_{\text{goal}}) = \emptyset
$$

#### Инвариант 2а (Транзитивная интервально-предикатная выполнимость путей — Multi-Hop Abstract Interval Interpretation)

Проверка совместимости предикатов только на смежных ребрах $(e_{\text{in}}, e_{\text{out}})$ одной вершины $w$ (1-hop check) слепа к **транзитивным многошаговым противоречиям**: если ребро $e_1 = (u_1, u_2)$ требует $s.x \in [10, 20]$, транзитный узел $u_2$ и ребро $e_2 = (u_2, u_3)$ вообще не упоминают и не модифицируют ключ $x$ ($x \notin W(u_2) \cup W(u_3)$), а ребро $e_3 = (u_3, u_4)$ требует $s.x \in [0, 5]$, то локальные 1-шаговые проверки в $u_2$ и $u_3$ пройдут успешно, хотя любой маршрут через $u_1 \to u_2 \to u_3 \to u_4$ гарантированно рухнет в $\mathcal{D}_{\text{stall}}$.

Поэтому над решеткой интервальных абстрактных состояний $\mathcal{A}_v: \mathcal{K}_t \to \text{Intervals}(\text{Dom}(k))$ запускается **прямая абстрактная интерпретация с распространением ограничений до неподвижной точки (Forward Dataflow Interval Propagation)**:

1. **Инициализация на входе:** $\mathcal{A}_{v_{\text{start}}}^{(0)}(k) = \text{Dom}(k)$ для всех $k \in \mathcal{K}_t$.

2. **Трансферная функция вершины и ребра** $e = (u, v)$: если вершина $u$ модифицирует ключ ($k \in W(u)$), интервал после $u$ расширяется до выходного домена $\text{Dom}_{\text{out}}(u, k)$; если же $k \notin W(u)$, интервал наследуется с входа $\mathcal{A}_u(k)$ и сужается предикатом ребра $\mathcal{I}_e(k)$:

$$
\mathcal{T}_e\big(\mathcal{A}_u\big)(k) = \begin{cases} \text{Dom}_{\text{out}}(u, k) \cap \mathcal{I}_e(k), & \text{если } k \in W(u), \\ \mathcal{A}_u(k) \cap \mathcal{I}_e(k), & \text{если } k \notin W(u). \end{cases}
$$

3. **Оператор слияния (Join) в вершине** $v$: ребро $e = (u, v)$ является *семантически проходимым* ($\text{Feasible}(e) = 1$), если для всех $k \in \mathcal{K}_t$ пересечение $\mathcal{T}_e(\mathcal{A}_u)(k) \neq \emptyset$. Абстрактное состояние в вершине $v$ есть объединение (выпуклая оболочка $\sqcup$) по всем семантически проходимым входящим ребрам:

$$
\mathcal{A}_v = \bigsqcup_{\substack{e=(u,v) \in \text{In}(v) \\ \text{Feasible}(e) = 1}} \mathcal{T}_e\big(\mathcal{A}_u\big)
$$

Для каждой достижимой нетерминальной вершины $w \in V_{\text{reach}}(v_{\text{start}}) \setminus V_{\text{goal}}$ должно существовать хотя бы одно семантически проходимое исходящее ребро $e_{\text{out}} = (w, v) \in \text{Out}(w)$, ведущее в ко-достижимое подмножество цели:

$$
\text{SatPath}_{\text{trans}}(w) \iff \exists e_{\text{out}} = (w, v) \in \text{Out}(w): \quad \big(v \in V_{\text{coreach}}(V_{\text{goal}})\big) \land \Big(\forall k \in \mathcal{K}_t: \mathcal{T}_{e_{\text{out}}}(\mathcal{A}_w)(k) \neq \emptyset\Big)
$$

Множество вершин с транзитивно невыполнимыми путями $V_{\text{unsat}}(G) = \{w \in V_{\text{reach}} \setminus V_{\text{goal}} \mid \neg \text{SatPath}_{\text{trans}}(w)\}$ обязано быть пустым: $V_{\text{unsat}}(G) = \emptyset$.

#### Инвариант 3 (Разрешимость циклов по Тарьяну — Non-Trapping SCC)

Для каждой нетривиальной компоненты сильной связности $C_k \in \text{SCC}_{\text{cyc}}(G)$ должны выполняться два условия:

1. **Существование ребра выхода (Escape Edge):** $\exists u \in C_k, \exists w \in V \setminus C_k : (u, w) \in E \land w \in V_{\text{coreach}}(V_{\text{goal}})$.

2. **Модификация состояния и предел итераций:** $\exists v \in C_k : W(v) \cap R(\Gamma(u, w)) \neq \emptyset$ при заданном лимите $L(C_k) \le L_{\max}$.

Если нарушен Инвариант 2, Инвариант 2а или Инвариант 3, верификатор возвращает вердикт $\text{HARD\_REJECT}$.

#### Определение 5 (Структурный штраф топологии $\Omega(G)$)

Для графов, прошедших жесткую проверку, вычисляется непрерывный функционал топологической сложности $\Omega(G) \ge 0$:

$$
\Omega(G) = \lambda_1 \cdot \max\left(0, \frac{\vert E\vert}{\vert V\vert} - \rho_{\max}\right) + \lambda_2 \cdot N_{\text{ambig}}(G) + \lambda_3 \cdot \sum_{C_k \in \text{SCC}_{\text{cyc}}(G)} \max\left(0, \vert C_k\vert - L_{\max}\right) + \lambda_4 \cdot \big(\vert V_{\text{dead}}(G)\vert + \vert V_{\text{unsat}}(G)\vert\big)
$$

### 2.3. Глобальная функция полезности, лагранжевы теневые цены ресурсов, ретроактивная поправка аудита $Y_{\text{ext}}$ и взвешенная конформная оценка (WC-LCB-DR-OPE)

#### Определение 6 (Базовая сессионная полезность, лагранжева адаптация цен ресурсов, калибровка критика $Q_{\text{sem}}$ и ретроактивная поправка аудита)

Для траектории $\tau$ с финальным состоянием $s_T$, числом шагов $N_{\text{steps}}$, расходом токенов $C_{\text{tokens}}$, задержкой $T_{\text{lat}}$ и числом откатов $N_{\text{rollbacks}}$ базовая полезность определяется с участием параметрического семантического критика $Q_{\text{sem}}(s_0, s_T; \phi) \in [0, 1]$ и **динамических двойственных весов ресурсов** $(w_s^{(t)}, w_c^{(t)}, w_t^{(t)}, w_r)$:

$$
U_{\text{base}}(\tau) = \mathbb{I}(\text{goal}(\tau)) \cdot Q_{\text{sem}}(s_0, s_T; \phi) \cdot R_{\max} - \left( w_s^{(t)} \frac{N_{\text{steps}}}{T_{\max}} + w_c^{(t)} \frac{C_{\text{tokens}}}{C_{\max}} + w_t^{(t)} \frac{T_{\text{lat}}}{T_{\text{SLA}}} + w_r N_{\text{rollbacks}} \right)
$$

**Лагранжева саморегуляция теневых цен ресурсов (Primal-Dual Resource Shadow Pricing):** веса стоимости ресурсов $w_q^{(t)} = w_{q,\text{min}} + \mu_{q,\text{dual}}^{(t)}$ ($q \in \{\text{steps}, \text{tokens}, \text{lat}\}$) обновляются методом двойственного градиентного подъема по невязке относительно целевых квот потребления $B_{q,\text{target}}$:

$$
\mu_{q,\text{dual}}^{(t+1)} = \max\left(0, \; \mu_{q,\text{dual}}^{(t)} + \eta_{\text{dual}} \cdot \left( \overline{\text{Usage}}_q^{(t)} - B_{q,\text{target}} \right)\right)
$$

**Калибровка критика и ретроактивная поправка исторических оценок при поступлении отложенного аудита (Retroactive Audit Credit Backpropagation):** в фазе «Сна» параметры критика $\phi$ калибруются по отложенному внешнему сигналу валидности $Y_{\text{ext}}(\tau) \in \{0, 1\}$:

$$
\phi^* = \arg\min_{\phi} \mathbb{E}_{(\tau, Y_{\text{ext}}) \sim \mathcal{D}_{\text{audit}}} \Big[ \mathcal{L}_{\text{BCE}}\big(Q_{\text{sem}}(s_0, s_T; \phi), \, Y_{\text{ext}}(\tau)\big) \Big]
$$

Поскольку сигнал $Y_{\text{ext}}(\tau)$ поступает с задержкой $\Delta t_{\text{audit}}$, прецеденты $c$, участвовавшие в траектории $\tau$, изначально получают оценку $\Delta U_i(c)$ на базе до-калибровочного предсказания $Q_{\text{sem}}(\tau; \phi_{\text{old}})$. Чтобы устранить накопленное смещение от временно обманутого или раскалиброванного критика, при поступлении фактической метки $Y_{\text{ext}}(\tau)$ к накопленной полезности и счетчикам каждого задействованного в $\tau$ прецедента $c_k$ применяется **ретроактивный импульс коррекции**:

$$
\Delta U_{\text{retro}}(\tau, c_k) = \Delta U_{\text{old}}(\tau, c_k) + \frac{\gamma_{\text{td}}^{K - k}}{\sum_{j=1}^{K} \gamma_{\text{td}}^{K - j}} \cdot R_{\max} \cdot \Big( Y_{\text{ext}}(\tau) - Q_{\text{sem}}\big(s_0, s_T; \phi_{\text{old}}\big) \Big)
$$

Если после ретроактивной коррекции знак $\Delta U_{\text{retro}}(\tau, c_k)$ меняется с положительного на неположительный, счетчики прецедента синхронно корректируются ($\tilde{S}_{c_k} \gets \max(0, \tilde{S}_{c_k} - 1), \; \tilde{F}_{c_k} \gets \tilde{F}_{c_k} + 1$).

#### Определение 6а (Автоматическая индукция контрактных проверок — Failure-Driven `Check` Synthesis)

На выборке поздних отказов $\mathcal{D}_{\text{late\_fail}}$ (траекторий, отвергнутых в конце сессии критиком $Q_{\text{sem}} < \theta_{\text{fail}}$ или $Y_{\text{ext}} = 0$) для каждого промежуточного узла $v$ индуцируется булев предикат раннего перехвата ошибок $\text{Assert}_v^* \in \mathcal{H}_{\text{pred}}$:

$$
\text{Assert}_v^* = \arg\max_{h \in \mathcal{H}_{\text{pred}}} \Big( \text{TPR}\big(h(s_v) = 0 \mid \tau \in \mathcal{D}_{\text{late\_fail}}\big) - \lambda_{\text{fp}} \cdot \text{FPR}\big(h(s_v) = 0 \mid \tau \in \mathcal{D}_{\text{ok}}\big) \Big)
$$

При $\text{FPR}(\text{Assert}_v^*) \le \alpha_{\text{check}}$ и $\text{TPR}(\text{Assert}_v^*) \ge \theta_{\text{catch}}$ после вершины $v$ автоматически инжектируется узел проверки $v_{\text{check}}$ с предикатом $\text{Assert}_v^*$.

#### Определение 7 (Полная полезность $U_{\text{total}}$, TD-кредит и взвешенная конформная дважды робастная оценка WC-LCB-DR-OPE)

Итоговая оценка сессии с учетом топологического здоровья графа $G_K$:

$$
U_{\text{total}}(\tau, G_K) = U_{\text{base}}(\tau) - \Omega(G_K)
$$

Для цепочки из $K \ge 1$ выживших мутаций $m_1, \dots, m_K$ вклад $k$-й мутации вычисляется через дисконтированное распределение кредита по временным разностям:

$$
\Delta U(m_k) = \frac{\gamma_{\text{td}}^{K - k}}{\sum_{j=1}^{K} \gamma_{\text{td}}^{K - j}} \cdot \big(U_{\text{base}}(\tau) - U_{\text{fail}}\big) - \Delta C_k - \Delta \Omega(m_k)
$$

**Взвешенная конформная дважды робастная каузальная коррекция (Covariate-Shift Weighted Conformal LCB-DR-OPE):** истинная полезность рецепта $c$ оценивается через **пессимистичный конформный дважды робастный функционал**:

$$
\overline{\Delta U}_c^{\text{DR-LCB}} = \frac{1}{N_c} \sum_{i=1}^{N_c} \left[ \hat{R}_\psi(x_i, c) - \big(1 - \mathbb{I}(\text{exec}_i)\big) \cdot \xi_{\text{ood}} \, \hat{q}_{1-\alpha_{\text{conf}}}^{\text{WC}}(x_i, c) + \min\left(W_{\max}, \, \frac{\mathbb{I}(\text{exec}_i)}{p_{\text{prop}}(x_i)}\right) \cdot \Big( \Delta U_i^{\text{retro}}(c) - \hat{R}_\psi(x_i, c) \Big) \right]
$$

где $\hat{q}_{1-\alpha_{\text{conf}}}^{\text{WC}}(x_i, c)$ — **взвешенный по сдвигу ковариат (Tibshirani Weighted Split-Conformal) квантиль** абсолютных невязок регрессора $r_j = \vert \Delta U_j - \hat{R}_\psi(x_j, c_j) \vert$ на калибровочном буфере $\mathcal{B}_{\text{cal}}$:

$$
\hat{q}_{1-\alpha_{\text{conf}}}^{\text{WC}}(x_i, c) = \inf \left\{ q \in \mathbb{R}_+ \;\Big|\; \sum_{j \in \mathcal{B}_{\text{cal}}} p_j^{\text{shift}}(x_i) \, \mathbb{I}(r_j \le q) \ge 1 - \alpha_{\text{conf}} \right\}, \quad p_j^{\text{shift}}(x_i) = \frac{\exp\big(-\gamma_{\text{rbf}} \| \mathbf{v}_{\text{inc}}(x_j) - \mathbf{v}_{\text{inc}}(x_i) \|_2^2\big)}{\sum_{l \in \mathcal{B}_{\text{cal}}} \exp\big(-\gamma_{\text{rbf}} \| \mathbf{v}_{\text{inc}}(x_l) - \mathbf{v}_{\text{inc}}(x_i) \|_2^2\big) + 1}
$$

### 2.4. Математическая модель арбитра System-1 (`@receptron/laya`), дистилляция из System-2 и калиброванно-защищенная нестационарная мета-политика System-2

#### Прямой проход System-1 и контур дистилляции

Локальная модель принятия решений System-1 вычисляет индекс риска дрейфа $r_{\text{drift}}(x) \in [0, 1]$, связность с целью $s_{\text{coh}}(x) \in [0, 1]$ и калиброванную вероятность одобрения:

$$
P_{\text{approve}}(m \mid T_{\text{cal}}, W_{\text{proj}}) = \sigma\left(\frac{\ell_{\text{true}}(W_{\text{proj}} h(x)) - \ell_{\text{false}}(W_{\text{proj}} h(x))}{T_{\text{cal}}}\right)
$$

Критерий пропуска мутации в рантайм:

$$
\text{Gate}_{\text{Laya}}(m) \iff \big(r_{\text{drift}} \le \tau_{\text{drift}}\big) \land \big(s_{\text{coh}} \ge \tau_{\text{coh}}\big) \land \big(P_{\text{approve}}(m \mid T_{\text{cal}}, W_{\text{proj}}) \ge \tau_{\text{prob}}\big)
$$

В фазе «Сна» выполняются:

1. **Проекционная дистилляция знаний из System-2 в System-1:**

   $$
   \mathcal{L}_{\text{KD}}(W_{\text{proj}}) = \frac{1}{M} \sum_{i=1}^{M} \Big[ (1 - \lambda_{\text{kd}}) \mathcal{L}_{\text{BCE}}\big(P_{\text{approve}}(x_i), y_i\big) + \lambda_{\text{kd}} D_{\text{KL}}\big(q_i^{\text{Sys2}} \,\|\, P_{\text{approve}}(x_i)\big) \Big]
   $$

2. **Оптимизация температуры Платта** $T_{\text{cal}}^*$ **и порогов** $\boldsymbol{\tau}^*$**:** минимизация NLL и байесовского риска $C_{\text{FA}} \widehat{\text{FAR}}(\boldsymbol{\tau}) + C_{\text{FR}} \widehat{\text{FRR}}(\boldsymbol{\tau})$.

#### Нестационарное самообучение мета-арбитра System-2 с защитой CUSUM от раскалибровки критика (Calibration-Gated CUSUM Thompson Sampling)

Каждой паре $(d, o) \in \mathcal{D}_{\text{types}} \times \mathcal{O}_{\text{mut}}$ сопоставляется нестационарное апостериорное распределение $\text{Beta}(\alpha_{d,o}^{(t)}, \beta_{d,o}^{(t)})$.
Чтобы временная раскалибровка внутреннего критика $Q_{\text{sem}}$ (до прихода внешних меток $Y_{\text{ext}}$) не вызывала ложного срабатывания детектора разладки CUSUM и ошибочного стирания памяти прецедентов, шаг накопления статистики Пейджа — Хинкли взвешивается на коэффициент калибровочной достоверности критика $w_{\text{cal}}^{(t)} = \max\big(0, \, 1 - \frac{\widehat{\text{ECE}}(Q_{\text{sem}})}{\epsilon_{\text{critic}}}\big) \in [0, 1]$, где $\widehat{\text{ECE}}(Q_{\text{sem}}) = \vert \mathbb{E}[Q_{\text{sem}} - Y_{\text{ext}}] \vert$:

$$
Z_{\text{cusum}}^{(t)} = \max\Big(0, \; Z_{\text{cusum}}^{(t-1)} + w_{\text{cal}}^{(t)} \big(\hat{p}_0 - \mathbb{I}(\Delta U_t > 0)\big) - \nu_{\text{drift}}\Big), \quad \gamma_{\text{stat}}(t) = \exp\Big(-\lambda_{\text{cusum}} \cdot \max\big(0, \, Z_{\text{cusum}}^{(t)} - \theta_{\text{cusum}}\big)\Big)
$$

В спокойной среде ($Z_{\text{cusum}}^{(t)} \le \theta_{\text{cusum}}$) фактор дисконтирования $\gamma_{\text{stat}}(t) = 1$; при истинном сдвиге внешней среды ($Z_{\text{cusum}}^{(t)} > \theta_{\text{cusum}}$ при калиброванном критике $w_{\text{cal}}^{(t)} \approx 1$) старая информационная масса экспоненциально сбрасывается:

$$
\alpha_{d,o}^{(t+1)} = 1 + \gamma_{\text{stat}}(t) \big(\alpha_{d,o}^{(t)} - 1\big) + \sum_{m \in \mathcal{B}_{d,o}^{(t)}} \mathbb{I}(\Delta U(m) > 0), \quad \beta_{d,o}^{(t+1)} = 1 + \gamma_{\text{stat}}(t) \big(\beta_{d,o}^{(t)} - 1\big) + \sum_{m \in \mathcal{B}_{d,o}^{(t)}} \mathbb{I}(\Delta U(m) \le 0)
$$

### 2.5. Векторная память прецедентов, каузальное одеяло Маркова $\mathcal{MB}(v_t, G)$, адаптер Прокруста $R_{\text{emb}} \in \text{SO}(d)$ и субмодулярный Coreset

#### Определение 8 (Каузальное одеяло Маркова $\mathcal{MB}(v_t, G)$, мультимодальный вектор и тихоновское выравнивание на $\text{SO}(d)$)

Топологический контекст тупика вокруг вершины $v_t$ строится по **каузальному одеяло Маркова по потоку данных** $\mathcal{MB}(v_t, G)$, объединяющему прямых поставщиков ключей чтения $R(v_t)$, прямых потребителей ключей записи $W(v_t)$ и совладельцев этих потребителей со взвешиванием по Персонализированному PageRank на графе зависимостей данных $G_{\text{data}}$:

$$
\mathcal{MB}(v_t, G) = \underbrace{\big\{ u \in V \mid W(u) \cap R(v_t) \neq \emptyset \big\}}_{\text{Parents}_{\text{data}}(v_t)} \cup \underbrace{\big\{ w \in V \mid R(w) \cap W(v_t) \neq \emptyset \big\}}_{\text{Children}_{\text{data}}(v_t)} \cup \underbrace{\big\{ z \in V \mid W(z) \cap R(\text{Children}_{\text{data}}(v_t)) \neq \emptyset \big\}}_{\text{Spouses}_{\text{data}}(v_t)}
$$

Параметр телепортации Персонализированного PageRank $\alpha_{\text{ppr}} \in [0.05, 0.50]$ при агрегации эмбеддинга топологии $\hat{\mathbf{e}}_{\text{topo}}(\alpha_{\text{ppr}}) = \text{Norm}\big(\sum_{u \in \mathcal{MB}(v_t, G)} \pi_{\text{ppr}}(u \mid v_t, \alpha_{\text{ppr}}) \mathbf{e}_u\big)$ оптимизируется в фазе «Сна» совместно с весами модальностей $\mathbf{w} = (\alpha, \beta, \gamma) \in \Delta^2$.

К составному вектору применяется обучаемое ортогональное преобразование $R_{\text{emb}} \in \text{SO}(d)$ ($R_{\text{emb}}^T R_{\text{emb}} = I_d, \det R_{\text{emb}} = +1$):

$$
\mathbf{v}_{\text{inc}}(\mathbf{w}, R_{\text{emb}}, \alpha_{\text{ppr}}) = R_{\text{emb}} \cdot \frac{\alpha \hat{\mathbf{e}}_{\text{err}} + \beta \hat{\mathbf{e}}_{\text{topo}}(\alpha_{\text{ppr}}) + \gamma \hat{\mathbf{e}}_{\text{schema}}}{\|\alpha \hat{\mathbf{e}}_{\text{err}} + \beta \hat{\mathbf{e}}_{\text{topo}}(\alpha_{\text{ppr}}) + \gamma \hat{\mathbf{e}}_{\text{schema}}\|_2}
$$

Для защиты от **рангового вырождения в нуль-пространстве** при малом числе пар $M_{\text{pairs}} \ll d$ матрица $R_{\text{emb}}^*$ обновляется через **регуляризованную по Тихонову ортогональную задачу Прокруста с геодезическим якорем Фробениуса** к предыдущей матрице $R_{\text{emb}}^{(t-1)}$:

$$
R_{\text{emb}}^* = \arg\min_{R \in \text{SO}(d)} \left( \sum_{i=1}^{M_{\text{pairs}}} \left\| R \mathbf{v}_{\text{new}}(x_i) - \mathbf{v}_{\text{old}}(x_i^+) \right\|_2^2 + \lambda_{\text{iso}} \left\| R - R_{\text{emb}}^{(t-1)} \right\|_F^2 \right) = U \operatorname{diag}(1, \dots, 1, \det(UV^T)) V^T
$$

где $U \Sigma V^T = \sum_{i=1}^{M_{\text{pairs}}} \mathbf{v}_{\text{old}}(x_i^+) \mathbf{v}_{\text{new}}(x_i)^T + \lambda_{\text{iso}} R_{\text{emb}}^{(t-1)}$ имеет гарантированный полный ранг $d$ при любом $\lambda_{\text{iso}} > 0$.

#### Определение 9 (Нестационарная байесовская нижняя граница доверия к прецеденту)

Для каждого прецедента $c$ накопленные счетчики успехов и сбоев дисконтируются синхронно с калиброванным детектором разладки CUSUM ($\tilde{S}_c^{(t+1)} = \gamma_{\text{stat}}(t) \tilde{S}_c^{(t)} + \mathbb{I}(\text{succ})$, $\tilde{F}_c^{(t+1)} = \gamma_{\text{stat}}(t) \tilde{F}_c^{(t)} + \mathbb{I}(\text{fail})$) и уточняются ретроактивным аудитом $Y_{\text{ext}}$. При апостериорном среднем $\hat{p}_c = \frac{\tilde{S}_c + \alpha_0}{\tilde{S}_c + \tilde{F}_c + \alpha_0 + \beta_0}$ нижняя граница доверия равна:

$$
C_{\text{conf}}(c) = \max\left(0, \; \hat{p}_c - z_{1-\delta} \sqrt{\frac{\hat{p}_c (1 - \hat{p}_c)}{\tilde{S}_c + \tilde{F}_c + \alpha_0 + \beta_0 + 1}}\right)
$$

#### Определение 10 (Гибридное ранжирование с защитой редких прецедентов и взвешенным по полезности субмодулярным Coreset-сжатием)

Коэффициент временного затухания $\eta_{\text{loc}}(c) = \eta_0 \cdot \max\big(0, \frac{\bar{\sigma}_k(c) - \sigma_{\text{sparse}}}{1 - \sigma_{\text{sparse}}}\big)$ обращается в $0$ в разреженных областях пространства ($\bar{\sigma}_k(c) \le \sigma_{\text{sparse}}$), защищая редкие прецеденты от забывания. Интегральный скор кандидата $c$ с использованием взвешенной конформной оценки $\overline{\Delta U}_c^{\text{DR-LCB}}$:

$$
S_{\text{total}}(q, c) = \sigma_{\text{cos}}(\mathbf{v}_q, \mathbf{v}_c) \cdot \left[ \Big(1 + \mu_1 \tanh\big(\overline{\Delta U}_c^{\text{DR-LCB}}\big) + \mu_2 C_{\text{conf}}(c)\Big) e^{-\eta_{\text{loc}}(c) \cdot (t_{\text{now}} - t_{\text{last}}(c))} + \kappa_0 e^{-N_{\text{total}}/\tau_{\text{warm}}} \sqrt{\frac{2 \ln(N_{\text{total}} + 1)}{N_c + 1}} \right]
$$

**Взвешенное по полезности и редкости субмодулярное сжатие памяти (Utility- & Sparsity-Aware Facility Location Coreset):** при превышении емкости $\vert\mathcal{M}_{\text{mem}}\vert > M_{\max}$ отбор подмножества $\mathcal{C}^* \subset \mathcal{M}_{\text{mem}}$ мощности $M_{\text{target}}$ максимизирует монотонный субмодулярный функционал покрытия, учитывающий не только геометрическую близость и $C_{\text{conf}}(c)$, но и конформную полезность $\overline{\Delta U}_c^{\text{DR-LCB}}$ вместе с бонусом уникальности редких прецедентов:

$$
\mathcal{C}^* = \arg\max_{\mathcal{C} \subset \mathcal{M}_{\text{mem}}, \, \vert\mathcal{C}\vert \le M_{\text{target}}} \sum_{x \in \mathcal{M}_{\text{mem}}} \max_{c \in \mathcal{C}} \left[ \sigma_{\text{cos}}(\mathbf{v}_x, \mathbf{v}_c) \cdot C_{\text{conf}}(c) \cdot \Big(1 + \max\big(0, \tanh(\overline{\Delta U}_c^{\text{DR-LCB}})\big)\Big) \cdot \Big(1 + \mathbb{I}\big(\bar{\sigma}_k(c) \le \sigma_{\text{sparse}}\big)\Big) \right]
$$

Жадный алгоритм с ленивыми приоритетными очередями (Lazy Greedy) гарантирует $(1 - 1/e)$-аппроксимацию оптимума за время $O(\vert\mathcal{M}_{\text{mem}}\vert \log \vert\mathcal{M}_{\text{mem}}\vert)$.

#### Определение 11 (Оператор реляционного переноса рецепта $\Psi_{\text{adapt}}$ над каузальным одеялом Маркова)

Оператор заземления $\Psi_{\text{adapt}}(m_{\text{old}}, G_{\text{curr}}, v_t)$ ищет целевую вершину привязки $u^* \in \mathcal{MB}(v_t, G_{\text{curr}}) \cup \{v_t\}$ внутри каузального одеяла Маркова путем максимизации взвешенного индекса Жаккара по каузально очищенным и приведенным к каноническим корням ($\text{FindCanonical}$) входным и выходным контрактам данных $(R_{\text{anchor}}, W_{\text{anchor}})$:

$$
u^* = \arg\max_{u \in \mathcal{MB}(v_t, G_{\text{curr}}) \cup \{v_t\}} \left( \frac{1}{2} \frac{\vert R(u) \cap R_{\text{anchor}}\vert}{\vert R(u) \cup R_{\text{anchor}}\vert} + \frac{1}{2} \frac{\vert W(u) \cap W_{\text{anchor}}\vert}{\vert W(u) \cup W_{\text{anchor}}\vert} \right)
$$

### 2.6. Математика дистилляции, иерархии макронод, митоза узлов, каскада LLM и CEGIS-эволюции инструментов

#### Обратный каузальный срез, иерархия навыков и декапсуляция (`Unfold`)

По траектории восстановления $\tau_{\text{rec}}$ строится неподвижная точка обратного среза зависимостей данных $V_{\text{slice}}^* = \{v_{i_1}, \dots, v_{i_L}\}$, задающая тело `MacroNode` $M$ со строгим контрактом:

$$
S_{\text{in}}(M) = \bigcup_{r=1}^{L} \left( R(v_{i_r}) \setminus \bigcup_{q=1}^{r-1} W(v_{i_q}) \right), \quad S_{\text{out}}(M) = \left( \bigcup_{r=1}^{L} W(v_{i_r}) \right) \cap \left( K_{\text{goal}} \cup \bigcup_{u \in V \setminus V_{\text{slice}}^*} R(u) \right)
$$

Если пара макронод уровня $l$ имеет взаимную информацией переходов $I(M_a^{(l)}; M_b^{(l)}) \ge \theta_{\text{hier}}$ при $l < L_{\text{hier\_max}}$, они упаковываются в мета-макроноду $M^{(l+1)}$. При сбое внутри макроноды срабатывает оператор локальной декапсуляции $\text{Unfold}(G, v_t, G_M)$.

#### Определение 12 (Внутриузловая эволюция промптов и каскадное понижение ранга моделей — Intra-Node Prompt & Model-Tier Cascade)

1. **Эволюция промпта и Few-Shot банка:** для каждой вершины $v \in V$ типа $\mathcal{T}(v) = \text{llm}$ на буфере контрастных исправлений $\mathcal{B}_{\text{prompt}}(v)$ оптимизируются инструкция $p_v^*$ и демонстрации $D_v^*$ ($\vert D_v^*\vert \le k_{\text{shot}}$):

   $$
   (p_v^*, D_v^*) = \arg\max_{(p, D), \, \vert D\vert \le k_{\text{shot}}} \left( \frac{1}{\vert\mathcal{B}_{\text{val}}(v)\vert} \sum_{s \in \mathcal{B}_{\text{val}}(v)} \mathbb{E}_{y \sim \text{LLM}_v(s \mid p, D)} \big[\text{Assert}_{\text{next}}(y)\big] - \lambda_{\text{tok}} \cdot \text{Tokens}(p, D) \right)
   $$

2. **Каскадная маршрутизация калибра модели внутри узла (Model-Tier Cascading):** пусть $\mathcal{M}_{\text{tiers}} = \langle m_{\text{local\_slm}}, m_{\text{light}}, m_{\text{frontier}} \rangle$ — упорядоченная иерархия моделей по возрастанию стоимости $C(m_1) \ll C(m_2) \ll C(m_3)$. В рантайме с учетом двойственной цены токенов $w_c^{(t)}$ для входа $s_t$ выбирается **самая дешевая модель**, гарантирующая надежность не ниже эталона:

   $$
   m^*(v, s_t) = \arg\min_{m_r \in \mathcal{M}_{\text{tiers}}} \Big\{ w_c^{(t)} C(m_r) \;\Big|\; \widehat{\text{Pass}}_{\text{LCB}}\big(v, m_r \mid \psi_v^*(s_t)\big) \ge \widehat{\text{Pass}}\big(v, m_{\text{frontier}}\big) - \epsilon_{\text{tier}} \Big\}
   $$

#### Определение 12а (Направленная эволюция и ремонт кода инструментов — CEGIS Tool Patching)

Если инструмент $u^{(v)} \in \mathcal{R}_{\text{core}} \cup \mathcal{R}_{\text{sandbox}}$ выбрасывает ошибку на новом состоянии $s_{\text{fail}}$, состояние навечно добавляется в регрессионный пул $\mathcal{S}_{\text{test}}^{(t+1)}(u) = \mathcal{S}_{\text{test}}^{(t)}(u) \cup \{s_{\text{fail}}\}$. Арбитр System-2 синтезирует патч AST-кода $u^{(v+1)}$, который принимается тогда и только тогда, когда он устраняет сбой на $s_{\text{fail}}$ и сохраняет 100% обратную совместимость на всех прежних тестах:

$$
\text{AcceptPatch}(u^{(v)} \to u^{(v+1)}) \iff \Big( \text{err}\big(\Phi_{u^{(v+1)}}(s_{\text{fail}})\big) = \varnothing \Big) \land \Big( \forall s \in \mathcal{S}_{\text{test}}^{(t)}(u): \Phi_{u^{(v+1)}}(s) = \Phi_{u^{(v)}}(s) \Big)
$$

#### Определение 12б (Энтропийный митоз когнитивно перегруженных `llm`-узлов — Entropy-Driven Node Fission / Mitosis)

Если вершина $v \in V$ типа $\mathcal{T}(v) = \text{llm}$ с многокомпонентной схемой выхода $\vert W(v) \vert \ge 2$ демонстрирует высокую частоту отказов на downstream-проверке ($\widehat{\text{FailRate}}(v) > \theta_{\text{mitosis}}$) даже на старшем калибре модели $m_{\text{frontier}}$ и после оптимизации промпта $(p_v^*, D_v^*)$, в фазе «Сна» срабатывает оператор **митоза (расщепления) узла** $\text{SplitNode}(v \to v_1 \to v_2)$, который находит разбиение выходных ключей $W(v) = W_1 \sqcup W_2$ ($W_1 \neq \emptyset, W_2 \neq \emptyset$), минимизирующее условную взаимную информацию:

$$
(W_1^*, W_2^*) = \arg\min_{W_1 \sqcup W_2 = W(v)} I(W_1; \, W_2 \mid R(v))
$$

Вершина $v$ заменяется последовательной парой специализированных узлов $v_1 \to v_2$ с контрактами $(R(v_1) = R(v), \, W(v_1) = W_1^*)$ и $(R(v_2) = R(v) \cup W_1^*, \, W(v_2) = W_2^*)$ (либо параллельной парой при $I(W_1^*; W_2^* \mid R(v)) < \epsilon_{\text{cmi}}$).

### 2.7. Математическая модель фонового рефакторинга, символьной индукции признаков $\psi^*(s)$, парной CRN-SPSA настройки и амортизированной устойчивости по Ляпунову

В фоновом контуре Consolidation Loop решается задача условной структурной оптимизации графа $G$ на исторической выборке $\mathcal{D}_{\text{hist}}$ при помощи одиннадцати операторов:

 1. **Оператор отсечения мертвых ветвей (Dead-Branch Pruning):** удаление ребра $e = (u, v)$ при $N(u) \ge N_{\min}$, $\hat{P}(e \mid u) < \theta_{\text{prune}}$ и $V_{\text{dead}}(G \setminus \{e\}) = \emptyset$.

 2. **Оператор линейного слияния (Linear Chain Fusion):** сжатие последовательных детерминированных вершин $u \to v$ в композитную вершину $w_{\text{fused}}$ ($\Phi_{w_{\text{fused}}} = \Phi_v \circ \Phi_u$).

 3. **Оператор квотно-безопасного автоматического распараллеливания по условиям Бернштейна (Quota-Aware Auto-Parallelization) и бисимуляционной свертки:** если последовательная пара вершин $u \to v$ (после контрфактически безопасной каузальной очистки $R(u), R(v)$ по Определению 2а) не имеет зависимостей по данным и их суммарный вектор потребления внешних ресурсов не превышает квоту $\mathbf{B}_{\text{rate}}$:

    $$
    \text{BernsteinSafe}(u, v) \iff \big(W(u) \cap R(v) = \emptyset\big) \land \big(R(u) \cap W(v) = \emptyset\big) \land \big(W(u) \cap W(v) = \emptyset\big) \land \big(\text{Res}(u) + \text{Res}(v) \le \mathbf{B}_{\text{rate}}\big)
    $$

    то цепочка $u \to v$ трансформируется в параллельный блок `branch` $\rightrightarrows \{u, v\} \rightrightarrows$ `join`, а дублирующиеся параллельные ветки после 3-way бифуркаций сворачиваются по отношению бисимуляции $G / {\sim_{\text{bisim}}}$ (Определение 1б).

 4. **Символьная индукция признаков** $\psi_v^*(s)$ **и детерминизация по энтропии Шеннона (Symbolic Feature Induction & Determinization):** для каждой вершины $v$ типа $\mathcal{T}(v) = \text{llm}$ на выборке пар $(s_i, e_i)$ решается задача поиска оптимального дерева булевых предикатов ограниченной глубины $\psi_v^* \in \mathcal{H}_{\text{DT}}(R(v))$ по принципу минимальной длины описания (MDL):

    $$
    \psi_v^* = \arg\min_{\psi \in \mathcal{H}_{\text{DT}}(R(v))} \Big( H\big(E_{\text{out}}(v) \mid \psi(s)\big) + \lambda_{\text{MDL}} \cdot \text{Complexity}(\psi) \Big)
    $$

    Если для листа $\psi_v^*(s) = x$ при $N(v, x) \ge N_{\text{det}}$ условная энтропия $H(v \mid \psi_v^*(s) = x) < \theta_H$, вызов LLM для этого паттерна заменяется детерминированным `guard`-переходом.

 5. **Обратный оператор реактивации пластичности (Plasticity Unfreeze):** возврат детерминизированного узла в режим `llm` при падении выживаемости маршрута на $\Delta_{\text{drift}}$.

 6. **Оператор проактивного контрфактического синтеза (Counterfactual Dreaming в Shadow Sandbox):** фоновый поиск узкого места $v_{\text{bottle}} = \arg\max_{v \in V} \big(\hat{P}(\text{visit } v) \cdot \mathbb{E}[\text{Cost}(v)]\big)$ и генерация более дешевых альтернативных подграфов с проверкой в песочнице.

 7. **Оператор активного любопытства (Active Curriculum Generation):** генерация синтетических входов $s_0^{\text{synth}} = \arg\max_{s_0} H_{\text{epistemic}}(s_0)$ в зонах максимальной эпистемической неопределенности System-1.

 8. **Оптимальное распределение вычислительного бюджета «Сна» по ROI (Sleep Compute Allocation):** выбор подмножества задач консолидации, максимизирующего суммарный ожидаемый прирост полезности в рамках бюджета $B_{\text{sleep}}$.

 9. **Статистический критерий канареечного релиза (Canary Welch's Z-Test):** ступенчатая выкатка ($5\% \to 25\% \to 100\%$) с контролем $Z$-статистики Уэлча.

10. **Подавление дисперсии при саморегуляции мета-гиперпараметров фазы «Сна» через парные общие случайные числа (Paired CRN-SPSA with Momentum):** прямое применение стохастической аппроксимации SPSA на разных случайных подвыборках трафика страдает от высокой дисперсии оценки градиента из-за неоднородности входных задач $s_0$. Поэтому возмущенные конфигурации $\boldsymbol{\Psi}_{\text{meta}}^{(k)} \pm c_k \boldsymbol{\Delta}_k$ ($\Delta_{k,j} \sim \text{Rademacher}(\pm 1)$) сначала оцениваются на **одном и том же стратифицированном пуле парных клонов начальных состояний и сидов** $\mathcal{D}_{\text{paired}}^{(k)}$ (Common Random Numbers, $\xi_i^+ = \xi_i^-$):

    $$
    \widehat{\mathbf{g}}_{\text{CRN}}^{(k)} = \frac{1}{\vert\mathcal{D}_{\text{paired}}^{(k)}\vert} \sum_{s_0^{(i)} \in \mathcal{D}_{\text{paired}}^{(k)}} \frac{U_{\text{ext}}\big(s_0^{(i)}; \, \boldsymbol{\Psi}_{\text{meta}}^{(k)} + c_k \boldsymbol{\Delta}_k, \xi_i\big) - U_{\text{ext}}\big(s_0^{(i)}; \, \boldsymbol{\Psi}_{\text{meta}}^{(k)} - c_k \boldsymbol{\Delta}_k, \xi_i\big)}{2 c_k} \boldsymbol{\Delta}_k^{-1}
    $$

    Обновление выполняется со сглаживанием импульса (EMA Momentum $\beta_{\text{mom}} \in [0.8, 0.95]$) и проекцией на доверительный гиперкуб $\mathcal{H}_{\text{box}}$:

    $$
    \mathbf{m}_{\Psi}^{(k+1)} = \beta_{\text{mom}} \mathbf{m}_{\Psi}^{(k)} + (1 - \beta_{\text{mom}}) \widehat{\mathbf{g}}_{\text{CRN}}^{(k)}, \qquad \boldsymbol{\Psi}_{\text{meta}}^{(k+1)} = \text{Proj}_{\mathcal{H}_{\text{box}}}\Big(\boldsymbol{\Psi}_{\text{meta}}^{(k)} + \eta_{\text{meta}}^{(k)} \mathbf{m}_{\Psi}^{(k+1)}\Big)
    $$

11. **Двухмасштабная координация скоростей обучения и амортизированный фильтр устойчивости Ляпунова (Two-Timescale Coordination & Amortized Horizon Lyapunov Filter):**

    * **Иерархия шагов обучения Боркара:**

      $$
      \eta_{\text{prompt}} \gg \eta_{\text{topo}} \gg \eta_{\text{sys1}} \gg \eta_{\text{meta}}, \qquad \lim_{t \to \infty} \frac{\eta_{\text{slow}}^{(t)}}{\eta_{\text{fast}}^{(t)}} = 0
      $$

    * **Глобальная функция энергии Ляпунова** $\mathcal{V}_{\text{Lyap}}(\Theta_t) \ge 0$ для полного вектора параметров системы $\Theta_t = (G_t, p_t, W_{\text{proj}}^{(t)}, R_{\text{emb}}^{(t)}, \mathbf{w}^{(t)}, \phi^{(t)}, \boldsymbol{\mu}_{\text{dual}}^{(t)}, \boldsymbol{\Psi}_{\text{meta}}^{(t)})$:

      $$
      \mathcal{V}_{\text{Lyap}}(\Theta_t) = \mathbb{E}_{\tau \sim \mathcal{D}_{\text{val}}} \Big[ R_{\max} - U_{\text{base}}(\tau \mid \Theta_t) \Big] + \Omega(G_t) + \beta_{\text{kl}} D_{\text{KL}}\big(\pi_{\Theta_t} \,\|\, \pi_{\Theta_{t-1}}\big)
      $$

    * **Амортизированное условие диссипативности с кредитным бюджетом структурной разведки** $B_{\text{lyap}}^{(t)}$**:**

      1. *Безусловная диссипация:* $\Delta \mathcal{V}_{\text{Lyap}}(\Theta_t) = \mathcal{V}_{\text{Lyap}}(\Theta_{t+1}) - \mathcal{V}_{\text{Lyap}}(\Theta_t) \le -\delta_{\text{lyap}} < 0$, при этом банк разведки пополняется: $B_{\text{lyap}}^{(t+1)} = \min\big(B_{\text{lyap\_max}}, \, B_{\text{lyap}}^{(t)} + \frac{1}{2}\vert\Delta \mathcal{V}_{\text{Lyap}}(\Theta_t)\vert\big)$;

      2. *Амортизированная двухшаговая инвестиция:* если $\Delta \mathcal{V}_{\text{Lyap}}(\Theta_t) \in (0, \, B_{\text{lyap}}^{(t)}]$, шаг допускается в статусе `PROVISIONAL` со списанием кредита $B_{\text{lyap}}^{(t+1)} = B_{\text{lyap}}^{(t)} - \Delta \mathcal{V}_{\text{Lyap}}(\Theta_t)$ при условии, что суммарное приращение энергии за окно $H_{\text{lyap}}$ эпох остается строго отрицательным:

         $$
         \mathcal{V}_{\text{Lyap}}(\Theta_{t + H_{\text{lyap}}}) - \mathcal{V}_{\text{Lyap}}(\Theta_t) \le -H_{\text{lyap}} \cdot \delta_{\text{lyap}} < 0
         $$

      При невыполнении этого условия по истечении окна $H_{\text{lyap}}$ система автоматически откатывается к контрольной точке $\Theta_t$.

* **Контур X аудита (Пробелы 36–39):** закрыты семантическая невыполнимость цепочек `guard`-предикатов ($\text{SatPath}$), каузальная очистка контрактов чтения $R(v)$ от ложных зависимостей, взвешенный конформный квантиль Тибширани при сдвиге ковариат и энтропийный митоз когнитивно перегруженных `llm`-узлов ($\text{SplitNode}$).

* **Контур XI аудита (Пробелы 40–43):** закрыты проверка структурного подтипирования Лисков ($\preceq_{\text{sub}}$) в $\text{MetaInit}$, защита редких хвостовых триггеров через $\text{CMI}_{\text{UCB}}$ и контрфактическую чувствительность $\text{Sens}_{\text{cf}} = 0$, двойственные лагранжевы цены ресурсов $\mu_{q,\text{dual}}^{(t+1)}$ и сжатие транзитивных путей алиасов ($\text{FindCanonical}$) со сборкой мусора в $\mathcal{K}_{\text{staging}}$.

#### Контур XII (Финальный аудит 12-го порядка): Транзитивная абстрактная интерпретация путей, реестр морфизмов схем $\mathcal{M}_{\text{coerce}}$, ретроактивная поправка отложенного аудита $Y_{\text{ext}}$ и парная CRN-SPSA регуляризация (Пробелы 44–47)

44. **Близорукость одношаговой проверки совместимости `guard`-интервалов на длинных транзитных цепочках (`1-Hop Myopia in Path Satisfiability`):**

    * *Диагностика:* в прежней редакции Инварианта 2а условие $\text{SatPath}(e_{\text{in}}, w)$ проверяло пересечение интервалов $\mathcal{I}_{e_{\text{in}}}(k) \cap \mathcal{I}_{e_{\text{out}}}(k) \neq \emptyset$ только между непосредственным входом и выходом одного узла $w$. Если ребро $e_1 = (u_1, u_2)$ требовало $s.x \in [10, 20]$, транзитный узел $u_2$ и ребро $e_2 = (u_2, u_3)$ вообще не проверяли и не меняли ключ $x$, а ребро $e_3 = (u_3, u_4)$ требовало $s.x \in [0, 5]$, то локальные 1-шаговые проверки в $u_2$ и $u_3$ проходили успешно, пропуская в рантайм заведомо непроходимый многошаговый маршрут.

    * *Математическое закрытие (Раздел 2.2, Инвариант 2а):* локальная проверка обобщена до **прямой абстрактной интерпретации интервалов до неподвижной точки (Forward Dataflow Interval Propagation)** $\mathcal{A}_v(k)$, транзитивно протягивающей ограничения неизменяемых ключей сквозь произвольное число промежуточных вершин.

45. **Отсутствие верифицированной логики трансформации и переиспользования у узлов-коэрсеров схем (`Untyped Placeholder Coercers in MetaInit`):**

    * *Диагностика:* в Определении 1а и методе `metaInitialize` при нарушении условия подтипирования Лисков ($\text{Dom}_{\text{out}}(w, k) \not\preceq_{\text{sub}} \text{Dom}_{\text{in}}(u, k)$) между узлами вставлялся пустой узел-заглушка `coerce_before_${s.id}` без синтезированного и проверенного закона преобразования данных и без сохранения этого адаптера для будущих графов.

    * *Математическое закрытие (Раздел 2.1, Определение 1а):* введен **обучаемый реестр морфизмов приведения схем** $\mathcal{M}_{\text{coerce}}$, где каждый адаптер $\Phi_{\text{coerce}}$ синтезируется через CEGIS на граничных точках $\text{Dom}_{\text{bound}}(\text{Dom}_{\text{out}})$ и кэшируется по паре хэшей JSON-схем для мгновенного $O(1)$ переиспользования между задачами.

46. **Запаздывание внешнего аудита $Y_{\text{ext}}$ и ложное срабатывание сброса памяти CUSUM при временной раскалибровке критика (`Audit Lag & False CUSUM Reset`):**

    * *Диагностика:* в Определении 6 внешний сигнал $Y_{\text{ext}}(\tau)$ приходит с задержкой $\Delta t_{\text{audit}}$. За это время исторические прецеденты уже успевают получить завышенные или заниженные оценки $\Delta U_i$ от раскалиброванного критика $Q_{\text{sem}}(\phi_{\text{old}})$, а сам детектор CUSUM может ложно сработать от ошибки критика, стерев валидную память прецедентов.

    * *Математическое закрытие (Раздел 2.3, Определение 6 и Раздел 2.4):* введены **ретроактивная поправка кредита** $\Delta U_{\text{retro}}(\tau, c_k)$ при поступлении $Y_{\text{ext}}(\tau)$ и взвешивание шага CUSUM на коэффициент калибровочной надежности критика $w_{\text{cal}}^{(t)} = \max\big(0, 1 - \widehat{\text{ECE}}(Q_{\text{sem}})/\epsilon_{\text{critic}}\big)$.

47. **Высокая дисперсия градиента SPSA на шумных когортах и отсутствие весов полезности в формуле Coreset-сжатия (`SPSA Variance & Utility-Blind Coreset`):**

    * *Диагностика:* в Операторе 10 (Раздел 2.7) оценка градиента SPSA на разных случайных задачах из-за высокой дисперсии стоимости траекторий приводила к зашумлению шага $\boldsymbol{\Psi}_{\text{meta}}$, а в Определении 10 отбор Coreset не учитывал конформную полезность $\overline{\Delta U}_c^{\text{DR-LCB}}$ и индикатор разреженности $\mathbb{I}(\bar{\sigma}_k(c) \le \sigma_{\text{sparse}})$.

    * *Математическое закрытие (Раздел 2.5, Определение 10 и Раздел 2.7, Оператор 10):* формализованы взвешенный по полезности и редкости функционал Facility Location Coreset и **парный антитетический градиент CRN-SPSA с общими случайными числами и импульсом** $\mathbf{m}_{\Psi}^{(k+1)}$.

## ПРИЛОЖЕНИЕ Б. ЭТАЛОННАЯ РЕАЛИЗАЦИЯ ЯДРА И РАНТАЙМ-ОРКЕСТРАТОРА НА NODE.JS

```javascript
import crypto from 'node:crypto';
import vm from 'node:vm';

/**
 * 1. Ориентированный граф с поддержкой типобезопасного MetaInit и кэша морфизмов приведения схем,
 *    Каузального одеяла Маркова, UCB-CMI контрфактически безопасной очистки контрактов чтения,
 *    Pushout/3-Way Бифуркации, Бисимуляционной свертки и Энтропийного митоза узлов.
 */
export class DirectedGraph {
  static schemaMorphismRegistry = new Map(); // `${hashOut}->${hashIn}` -> { code, fn }

  constructor(id = 'default_graph') {
    this.id = id;
    this.nodes = new Map();
    this.edges = new Map();
    this.startNode = null;
    this.goalNodes = new Set();
  }

  addNode(node) {
    this.nodes.set(node.id, {
      id: node.id,
      type: node.type,
      reads: Array.from(new Set(node.reads || [])),
      writes: Array.from(new Set(node.writes || [])),
      inputSchemas: node.inputSchemas || {},
      outputSchemas: node.outputSchemas || {},
      idempotency: node.idempotency || 'pure',
      hasBarrier: Boolean(node.hasBarrier),
      resourceRps: node.resourceRps ?? 1.0,
      modelTier: node.modelTier || 'frontier',
      config: node.config || {}
    });
    if (!this.edges.has(node.id)) this.edges.set(node.id, []);
    return this;
  }

  addEdge(from, to, guardFn = () => true, priority = 10, guardMeta = null) {
    if (!this.edges.has(from)) this.edges.set(from, []);
    this.edges.get(from).push({
      from,
      to,
      guard: guardFn,
      priority,
      guardExpr: guardMeta?.expr || guardFn.toString(),
      intervals: guardMeta?.intervals || {} // { key: [min, max] } для проверки Инварианта 2а
    });
    this.edges.get(from).sort((a, b) => a.priority - b.priority);
    return this;
  }

  /**
   * Определение 8 & 11: Вычисление каузального одеяла Маркова MB(v_t, G)
   * с весами Персонализированного PageRank по графу потока данных.
   */
  getCausalMarkovBlanket(centerNodeId, alphaPpr = 0.15) {
    const center = this.nodes.get(centerNodeId);
    if (!center) return new Map();

    const centerReads = new Set(center.reads);
    const centerWrites = new Set(center.writes);
    const parents = new Set();
    const children = new Set();
    const childReads = new Set();

    for (const [id, node] of this.nodes.entries()) {
      if (id === centerNodeId) continue;
      if (node.writes.some((k) => centerReads.has(k))) parents.add(id);
      if (node.reads.some((k) => centerWrites.has(k))) {
        children.add(id);
        node.reads.forEach((k) => childReads.add(k));
      }
    }

    const spouses = new Set();
    for (const [id, node] of this.nodes.entries()) {
      if (id !== centerNodeId && !parents.has(id) && !children.has(id)) {
        if (node.writes.some((k) => childReads.has(k))) spouses.add(id);
      }
    }

    const blanketIds = new Set([centerNodeId, ...parents, ...children, ...spouses]);
    const scores = new Map();
    for (const id of blanketIds) {
      const dist = id === centerNodeId ? 0 : (parents.has(id) || children.has(id) ? 1 : 2);
      scores.set(id, alphaPpr * Math.pow(1 - alphaPpr, dist));
    }
    return scores;
  }

  /**
   * Определение 2а: Контрфактически безопасная каузальная очистка контрактов чтения R(v)
   * через верхнюю доверительную границу CMI_UCB и проверку нулевой чувствительности Sens_cf = 0.
   */
  deflateSpuriousReadContracts(cmiStatsMatrix, epsilonCmi = 0.02, cCmi = 0.15) {
    let prunedCount = 0;
    for (const [nodeId, node] of this.nodes.entries()) {
      const nodeStats = cmiStatsMatrix.get(nodeId);
      if (!nodeStats || node.reads.length <= 1) continue;
      const filteredReads = node.reads.filter((k) => {
        const stat = nodeStats.get(k);
        if (!stat) return true;
        const nTotal = Math.max(2, stat.totalRuns ?? 40);
        const nEff = Math.max(0, stat.minorityRuns ?? 0);
        const cmiUcb = (stat.empiricalCmi ?? 0) + cCmi * Math.sqrt(Math.log(nTotal) / (nEff + 1));
        const cfSens = stat.counterfactualSensitivity ?? 1.0;
        return !(cmiUcb < epsilonCmi && cfSens === 0);
      });
      if (filteredReads.length > 0 && filteredReads.length < node.reads.length) {
        prunedCount += node.reads.length - filteredReads.length;
        node.reads = filteredReads;
      }
    }
    return prunedCount;
  }

  /**
   * Определение 12б: Энтропийный митоз (расщепление) когнитивно перегруженного llm-узла.
   */
  splitOverloadedLlmNode(nodeId, partitionW1, partitionW2) {
    const node = this.nodes.get(nodeId);
    if (!node || node.type !== 'llm' || partitionW1.length === 0 || partitionW2.length === 0) {
      return false;
    }
    const node1Id = `${nodeId}_mitosis_1`;
    const node2Id = `${nodeId}_mitosis_2`;

    this.addNode({
      id: node1Id,
      type: 'llm',
      reads: [...node.reads],
      writes: [...partitionW1],
      modelTier: 'light',
      config: { ...node.config, role: 'subtask_part_1' }
    });
    this.addNode({
      id: node2Id,
      type: 'llm',
      reads: [...node.reads, ...partitionW1],
      writes: [...partitionW2],
      modelTier: 'light',
      config: { ...node.config, role: 'subtask_part_2' }
    });

    for (const [, edgeList] of this.edges.entries()) {
      for (const edge of edgeList) {
        if (edge.to === nodeId) edge.to = node1Id;
      }
    }
    const outgoing = this.edges.get(nodeId) || [];
    this.edges.set(node2Id, outgoing.map((e) => ({ ...e, from: node2Id })));
    this.edges.delete(nodeId);
    this.nodes.delete(nodeId);
    this.addEdge(node1Id, node2Id, () => true, 1);

    if (this.startNode === nodeId) this.startNode = node1Id;
    if (this.goalNodes.has(nodeId)) {
      this.goalNodes.delete(nodeId);
      this.goalNodes.add(node2Id);
    }
    return true;
  }

  /**
   * Определение 1а: Типобезопасный кросс-задачный мета-синтез стартового графа G_0^*
   * с проверкой структурного подтипирования Лисков и реестром морфизмов M_coerce.
   */
  static isJsonSchemaSubtype(outSchema, inSchema) {
    if (!outSchema || !inSchema) return true;
    if (outSchema.type !== inSchema.type) {
      return outSchema.type === 'integer' && inSchema.type === 'number';
    }
    if (outSchema.nullable === true && inSchema.nullable === false) return false;
    if (typeof inSchema.minimum === 'number' && (outSchema.minimum ?? -Infinity) < inSchema.minimum) {
      return false;
    }
    if (typeof inSchema.maximum === 'number' && (outSchema.maximum ?? Infinity) > inSchema.maximum) {
      return false;
    }
    return true;
  }

  static resolveOrSynthesizeSchemaMorphism(key, outSchema, inSchema) {
    const hashPair = crypto
      .createHash('sha256')
      .update(JSON.stringify({ outSchema, inSchema }))
      .digest('hex');
    if (DirectedGraph.schemaMorphismRegistry.has(hashPair)) {
      return DirectedGraph.schemaMorphismRegistry.get(hashPair);
    }
    const minBound = typeof inSchema?.minimum === 'number' ? inSchema.minimum : -Infinity;
    const maxBound = typeof inSchema?.maximum === 'number' ? inSchema.maximum : Infinity;
    const morphism = {
      id: `morphism_${hashPair.slice(0, 8)}`,
      transformKey: key,
      coercerFn: (val) => {
        const num = typeof val === 'number' ? val : Number(val ?? 0);
        const safe = Number.isNaN(num) ? (Number.isFinite(minBound) ? minBound : 0) : num;
        return Math.min(maxBound, Math.max(minBound, safe));
      }
    };
    DirectedGraph.schemaMorphismRegistry.set(hashPair, morphism);
    return morphism;
  }

  static metaInitialize(intentVector, initKeys, goalKeys, skillLibrary, costBudgetMax = 40.0, initSchemas = {}) {
    const g = new DirectedGraph('meta_synthesized_graph');
    const available = new Set(initKeys);
    const activeSchemas = { ...initSchemas };
    const selectedSkills = [];
    let totalExpectedCost = 0;

    g.addNode({ id: 'start', type: 'tool', reads: [], writes: Array.from(initKeys), outputSchemas: activeSchemas });
    g.startNode = 'start';

    let progress = true;
    while (progress && !goalKeys.every((k) => available.has(k))) {
      progress = false;
      let bestSkill = null;
      let bestScore = Infinity;

      for (const skill of skillLibrary) {
        const canRun = skill.reads.every((r) => available.has(r));
        const producesNew = skill.writes.some((w) => !available.has(w));
        if (canRun && producesNew && (totalExpectedCost + (skill.expectedCost || 5)) <= costBudgetMax) {
          const sim = Math.max(0.05, skill.similarityToIntent || 0.8);
          const score = (skill.expectedCost || 5) / ((skill.confidenceLcb || 0.8) * sim);
          if (score < bestScore) {
            bestScore = score;
            bestSkill = skill;
          }
        }
      }

      if (bestSkill) {
        selectedSkills.push(bestSkill);
        totalExpectedCost += bestSkill.expectedCost || 5;
        for (const w of bestSkill.writes) {
          available.add(w);
          if (bestSkill.outputSchemas?.[w]) activeSchemas[w] = bestSkill.outputSchemas[w];
        }
        progress = true;
      }
    }

    let prevId = 'start';
    for (const s of selectedSkills) {
      const mismatchedKeys = s.reads.filter(
        (k) => !DirectedGraph.isJsonSchemaSubtype(activeSchemas[k], s.inputSchemas?.[k])
      );
      if (mismatchedKeys.length > 0) {
        const coerceId = `coerce_before_${s.id}`;
        const morphisms = mismatchedKeys.map((k) =>
          DirectedGraph.resolveOrSynthesizeSchemaMorphism(k, activeSchemas[k], s.inputSchemas?.[k])
        );
        g.addNode({
          id: coerceId,
          type: 'tool',
          reads: mismatchedKeys,
          writes: mismatchedKeys,
          outputSchemas: s.inputSchemas || {},
          config: { morphisms: morphisms.map((m) => m.id) }
        });
        g.addEdge(prevId, coerceId, () => true, 1);
        prevId = coerceId;
      }
      g.addNode({
        id: s.id,
        type: s.type || 'macro',
        reads: s.reads,
        writes: s.writes,
        inputSchemas: s.inputSchemas,
        outputSchemas: s.outputSchemas
      });
      g.addEdge(prevId, s.id, () => true, 1);
      prevId = s.id;
    }
    g.addNode({ id: 'goal', type: 'check', reads: goalKeys, writes: [] });
    g.addEdge(prevId, 'goal', () => true, 1);
    g.goalNodes.add('goal');
    return g;
  }

  /**
   * Определение 1б: Алгебраический Pushout, 3-Way предикатная бифуркация и бисимуляционная свертка.
   */
  static tryPushoutOrBifurcateMerge(baseGraph, branchA, branchB) {
    const readsA = new Set(branchA.modifiedReads || []);
    const writesA = new Set(branchA.modifiedWrites || []);
    const readsB = new Set(branchB.modifiedReads || []);
    const writesB = new Set(branchB.modifiedWrites || []);

    const disjointNodes = !branchA.touchedNodes.some((n) => branchB.touchedNodes.includes(n));
    const noDataConflict =
      ![...writesA].some((k) => readsB.has(k) || writesB.has(k)) &&
      ![...writesB].some((k) => readsA.has(k) || writesA.has(k));

    if (disjointNodes && noDataConflict) {
      const merged = baseGraph.clone();
      branchA.applyTo(merged);
      branchB.applyTo(merged);
      return { merged: true, mode: 'PUSHOUT', graph: merged };
    }

    const sharedHotspots = branchA.touchedNodes.filter((n) => branchB.touchedNodes.includes(n));
    if (sharedHotspots.length === 1 && branchA.entryGuardDisjointFrom(branchB)) {
      const merged = baseGraph.clone();
      const hotspot = sharedHotspots[0];
      branchA.applyGuardedBranch(merged, hotspot, 1);
      branchB.applyGuardedBranch(merged, hotspot, 2);
      merged.foldBisimilarBranches();
      return { merged: true, mode: 'GUARDED_BIFURCATION_WITH_BISIM_FOLD', graph: merged };
    }

    return { merged: false, reason: 'REQUIRES_RELATIONAL_REBASE' };
  }

  /**
   * Определение 1б (п. 3): Обратная бисимуляционная свертка эквивалентных ветвей в ромб (DAG Diamond).
   */
  foldBisimilarBranches() {
    const signatureMap = new Map();
    for (const [id, node] of this.nodes.entries()) {
      if (id === this.startNode || this.goalNodes.has(id)) continue;
      const outTargets = (this.edges.get(id) || []).map((e) => e.to).sort().join(',');
      const sig = `${node.type}|R:${[...node.reads].sort()}|W:${[...node.writes].sort()}|fn:${node.config?.toolId || node.config?.promptHash || id}|out:${outTargets}`;

      if (signatureMap.has(sig)) {
        const canonicalId = signatureMap.get(sig);
        for (const [, edgeList] of this.edges.entries()) {
          for (const edge of edgeList) {
            if (edge.to === id) edge.to = canonicalId;
          }
        }
        this.edges.delete(id);
        this.nodes.delete(id);
      } else {
        signatureMap.set(sig, id);
      }
    }
    return this;
  }

  computeStructuralHash() {
    const payload = JSON.stringify({
      nodes: Array.from(this.nodes.entries()).sort(),
      edges: Array.from(this.edges.entries()).map(([k, v]) => [
        k,
        v.map((e) => ({ to: e.to, p: e.priority, g: e.guardExpr }))
      ])
    });
    return crypto.createHash('sha256').update(payload).digest('hex');
  }

  clone() {
    const copy = new DirectedGraph(this.id);
    copy.startNode = this.startNode;
    this.goalNodes.forEach((g) => copy.goalNodes.add(g));
    for (const [, node] of this.nodes) copy.addNode(structuredClone(node));
    for (const [from, edgeList] of this.edges) {
      for (const e of edgeList) {
        copy.addEdge(from, e.to, e.guard, e.priority, { expr: e.guardExpr, intervals: e.intervals });
      }
    }
    return copy;
  }
}

/**
 * 2. Менеджер онтологии ключей состояния K_t со сжатием транзитивных путей алиасов (Union-Find)
 *    и TTL-сборкой мусора в карантине K_staging (Определение 2).
 */
export class StateOntologyManager {
  constructor(stagingTtlEpochs = 5) {
    this.keys = new Map();
    this.stagingTtlEpochs = stagingTtlEpochs;
  }

  findCanonical(keyName) {
    const entry = this.keys.get(keyName);
    if (!entry || !entry.canonicalAlias || entry.canonicalAlias === keyName) return keyName;
    const root = this.findCanonical(entry.canonicalAlias);
    entry.canonicalAlias = root;
    return root;
  }

  mergeKeys(canonicalKey, synonymKey) {
    const rootA = this.findCanonical(canonicalKey);
    const rootB = this.findCanonical(synonymKey);
    if (rootA !== rootB && this.keys.has(rootB)) {
      this.keys.get(rootB).canonicalAlias = rootA;
    }
    return rootA;
  }

  runStagingGarbageCollection(thetaIg = 0.10) {
    const evicted = [];
    for (const [k, meta] of this.keys.entries()) {
      if (meta.status === 'STAGING') {
        meta.epochsLived = (meta.epochsLived || 0) + 1;
        if ((meta.mutualInfoGain || 0) >= thetaIg) {
          meta.status = 'CANONICAL';
        } else if (meta.epochsLived >= this.stagingTtlEpochs) {
          this.keys.delete(k);
          evicted.push(k);
        }
      }
    }
    return evicted;
  }
}

/**
 * 3. Верификатор ограниченного детерминизма, транзитивной абстрактной интерпретации интервалов (Инвариант 2а),
 *    функционала сложности Omega(G) и амортизированного фильтра Ляпунова.
 */
export class GraphDeterminismVerifier {
  constructor(config = {}) {
    this.rhoMax = config.rhoMax ?? 1.8;
    this.lMax = config.lMax ?? 5;
    this.weights = config.weights ?? { l1: 2.0, l2: 10.0, l3: 1.5, l4: 25.0 };
    this.lyapunovCreditBank = config.lyapunovCreditBankMax ?? 15.0;
  }

  verify(graph) {
    const V = graph.nodes.size;
    let E = 0;
    let priorityCollisions = 0;

    for (const [, list] of graph.edges) {
      E += list.length;
      const seenPriorities = new Set();
      for (const edge of list) {
        if (seenPriorities.has(edge.priority)) priorityCollisions++;
        seenPriorities.add(edge.priority);
      }
    }

    const reachable = this._bfsReachable(graph, graph.startNode);
    const coReachable = this._reverseBfsCoReachable(graph, graph.goalNodes);
    const deadNodes = Array.from(reachable).filter((n) => !coReachable.has(n));
    const unsatNodes = this._checkTransitivePathSatisfiability(graph, reachable, coReachable);
    const sccs = this._tarjanSCC(graph, reachable);
    const trappingCycles = [];
    let cycleExcess = 0;

    for (const comp of sccs) {
      const isCyclic =
        comp.length > 1 ||
        (comp.length === 1 && (graph.edges.get(comp[0]) || []).some((e) => e.to === comp[0]));
      if (isCyclic) {
        if (comp.length > this.lMax) cycleExcess += comp.length - this.lMax;
        const compSet = new Set(comp);
        const hasEscape = comp.some((u) =>
          (graph.edges.get(u) || []).some((e) => !compSet.has(e.to) && coReachable.has(e.to))
        );
        if (!hasEscape) trappingCycles.push(comp);
      }
    }

    const density = V > 0 ? E / V : 0;
    const omega =
      this.weights.l1 * Math.max(0, density - this.rhoMax) +
      this.weights.l2 * priorityCollisions +
      this.weights.l3 * cycleExcess +
      this.weights.l4 * (deadNodes.length + unsatNodes.length);

    const passed =
      priorityCollisions === 0 &&
      deadNodes.length === 0 &&
      unsatNodes.length === 0 &&
      trappingCycles.length === 0;

    return {
      status: passed ? 'PASS' : 'HARD_REJECT',
      omegaPenalty: Number(omega.toFixed(4)),
      diagnostics: { priorityCollisions, deadNodes, unsatNodes, trappingCycles }
    };
  }

  /**
   * Инвариант 2а (Контур XII): Многошаговая прямая абстрактная интерпретация интервалов
   * с протягиванием ограничений неизменяемых ключей сквозь транзитные узлы.
   */
  _checkTransitivePathSatisfiability(graph, reachable, coReachable) {
    const abstractState = new Map();
    for (const id of reachable) abstractState.set(id, {});

    const maxPasses = reachable.size + 1;
    for (let pass = 0; pass < maxPasses; pass++) {
      let changed = false;
      for (const uId of reachable) {
        const uNode = graph.nodes.get(uId);
        const writtenByU = new Set(uNode?.writes || []);
        const uIntervals = abstractState.get(uId) || {};

        for (const edge of graph.edges.get(uId) || []) {
          if (!reachable.has(edge.to)) continue;
          const transferred = {};
          let edgeFeasible = true;

          const allKeys = new Set([
            ...Object.keys(uIntervals),
            ...Object.keys(edge.intervals || {})
          ]);

          for (const k of allKeys) {
            const baseRange = writtenByU.has(k) ? [-Infinity, Infinity] : (uIntervals[k] || [-Infinity, Infinity]);
            const guardRange = edge.intervals?.[k] || [-Infinity, Infinity];
            const low = Math.max(baseRange[0], guardRange[0]);
            const high = Math.min(baseRange[1], guardRange[1]);
            if (low > high) {
              edgeFeasible = false;
              break;
            }
            transferred[k] = [low, high];
          }

          if (edgeFeasible) {
            const targetState = abstractState.get(edge.to) || {};
            for (const [k, [low, high]] of Object.entries(transferred)) {
              if (!targetState[k]) {
                targetState[k] = [low, high];
                changed = true;
              } else {
                const joinedLow = Math.min(targetState[k][0], low);
                const joinedHigh = Math.max(targetState[k][1], high);
                if (joinedLow !== targetState[k][0] || joinedHigh !== targetState[k][1]) {
                  targetState[k] = [joinedLow, joinedHigh];
                  changed = true;
                }
              }
            }
            abstractState.set(edge.to, targetState);
          }
        }
      }
      if (!changed) break;
    }

    const unsat = [];
    for (const wId of reachable) {
      if (graph.goalNodes.has(wId)) continue;
      const wNode = graph.nodes.get(wId);
      const writtenByW = new Set(wNode?.writes || []);
      const wIntervals = abstractState.get(wId) || {};
      const outgoing = (graph.edges.get(wId) || []).filter((e) => coReachable.has(e.to));
      if (outgoing.length === 0) continue;

      const hasFeasibleOut = outgoing.some((eOut) => {
        if (!eOut.intervals) return true;
        for (const [k, [gMin, gMax]] of Object.entries(eOut.intervals)) {
          const inRange = writtenByW.has(k) ? [-Infinity, Infinity] : (wIntervals[k] || [-Infinity, Infinity]);
          if (Math.max(inRange[0], gMin) > Math.min(inRange[1], gMax)) return false;
        }
        return true;
      });
      if (!hasFeasibleOut) unsat.push(wId);
    }
    return unsat;
  }

  verifyAmortizedLyapunovStability(prevEnergy, nextEnergy, deltaMin = 0.5, maxBank = 15.0) {
    const deltaV = nextEnergy - prevEnergy;
    if (deltaV <= -deltaMin) {
      this.lyapunovCreditBank = Math.min(maxBank, this.lyapunovCreditBank + 0.5 * Math.abs(deltaV));
      return { accepted: true, mode: 'STRICT_DISSIPATION', deltaV, bank: this.lyapunovCreditBank };
    }
    if (deltaV > 0 && deltaV <= this.lyapunovCreditBank) {
      this.lyapunovCreditBank -= deltaV;
      return { accepted: true, mode: 'PROVISIONAL_INVESTMENT', deltaV, bank: this.lyapunovCreditBank };
    }
    return { accepted: false, mode: 'REJECTED_BY_LYAPUNOV', deltaV, bank: this.lyapunovCreditBank };
  }

  _bfsReachable(graph, start) {
    const visited = new Set();
    if (!start) return visited;
    const queue = [start];
    while (queue.length > 0) {
      const curr = queue.shift();
      if (!visited.has(curr)) {
        visited.add(curr);
        for (const e of graph.edges.get(curr) || []) queue.push(e.to);
      }
    }
    return visited;
  }

  _reverseBfsCoReachable(graph, goals) {
    const rev = new Map();
    for (const [u, list] of graph.edges) {
      for (const e of list) {
        if (!rev.has(e.to)) rev.set(e.to, []);
        rev.get(e.to).push(u);
      }
    }
    const visited = new Set();
    const queue = Array.from(goals);
    while (queue.length > 0) {
      const curr = queue.shift();
      if (!visited.has(curr)) {
        visited.add(curr);
        for (const prev of rev.get(curr) || []) queue.push(prev);
      }
    }
    return visited;
  }

  _tarjanSCC(graph, subset) {
    let index = 0;
    const indices = new Map();
    const lowlink = new Map();
    const stack = [];
    const onStack = new Set();
    const sccs = [];

    const strongConnect = (v) => {
      indices.set(v, index);
      lowlink.set(v, index);
      index++;
      stack.push(v);
      onStack.add(v);

      for (const e of graph.edges.get(v) || []) {
        if (!subset.has(e.to)) continue;
        if (!indices.has(e.to)) {
          strongConnect(e.to);
          lowlink.set(v, Math.min(lowlink.get(v), lowlink.get(e.to)));
        } else if (onStack.has(e.to)) {
          lowlink.set(v, Math.min(lowlink.get(v), indices.get(e.to)));
        }
      }

      if (lowlink.get(v) === indices.get(v)) {
        const comp = [];
        let w;
        do {
          w = stack.pop();
          onStack.delete(w);
          comp.push(w);
        } while (w !== v);
        sccs.push(comp);
      }
    };

    for (const v of subset) {
      if (!indices.has(v)) strongConnect(v);
    }
    return sccs;
  }
}

/**
 * 4. Реестр инструментов с изолированной node:vm песочницей, CEGIS-патчингом
 *    и автоматической верификацией компенсирующих Saga-операторов (Определение 2).
 */
export class ToolRegistry {
  constructor() {
    this.tools = new Map();
  }

  register(toolSpec) {
    this.tools.set(toolSpec.id, {
      ...toolSpec,
      version: toolSpec.version || 1,
      hasIrreversibleBarrier: Boolean(toolSpec.hasIrreversibleBarrier),
      regressionPool: toolSpec.regressionPool || []
    });
  }

  executeSandboxed(codeStr, stateInput, timeoutMs = 250) {
    const sandbox = {
      input: structuredClone(stateInput),
      output: null,
      Math,
      Date,
      JSON
    };
    const context = vm.createContext(Object.freeze(sandbox));
    const script = new vm.Script(`output = (${codeStr})(input);`);
    script.runInContext(context, { timeout: timeoutMs });
    return sandbox.output;
  }

  verifyAndAttachSagaCompensator(toolId, compensatorCodeStr, epsilonSaga = 1e-4) {
    const tool = this.tools.get(toolId);
    if (!tool) throw new Error(`Tool ${toolId} not found`);

    let totalResidual = 0;
    const pool = tool.regressionPool.length > 0 ? tool.regressionPool : [{ sample: {} }];

    for (const tc of pool) {
      try {
        const forwardState = this.executeSandboxed(tool.sourceCode, tc.input ?? tc);
        const restoredState = this.executeSandboxed(compensatorCodeStr, forwardState);
        const keys = new Set([...(tool.reads || []), ...(tool.writes || [])]);
        for (const k of keys) {
          if (JSON.stringify((tc.input ?? tc)[k]) !== JSON.stringify(restoredState?.[k])) {
            totalResidual += 1.0;
          }
        }
      } catch {
        tool.hasIrreversibleBarrier = true;
        return { verified: false, hasBarrier: true };
      }
    }

    const avgError = totalResidual / pool.length;
    if (avgError <= epsilonSaga) {
      tool.sagaCompensatorCode = compensatorCodeStr;
      tool.sagaResidualError = avgError;
      tool.hasIrreversibleBarrier = false;
      return { verified: true, residualError: avgError, hasBarrier: false };
    }

    tool.hasIrreversibleBarrier = true;
    return { verified: false, residualError: avgError, hasBarrier: true };
  }

  patchToolWithCEGIS(toolId, candidateCodeStr, failingInputState) {
    const tool = this.tools.get(toolId);
    if (!tool) throw new Error(`Tool ${toolId} not found`);

    for (const testCase of tool.regressionPool) {
      const outNew = this.executeSandboxed(candidateCodeStr, testCase.input);
      if (JSON.stringify(outNew) !== JSON.stringify(testCase.expectedOutput)) {
        return { accepted: false, reason: 'REGRESSION_MISMATCH' };
      }
    }

    try {
      const fixedOut = this.executeSandboxed(candidateCodeStr, failingInputState);
      tool.regressionPool.push({ input: structuredClone(failingInputState), expectedOutput: fixedOut });
      tool.sourceCode = candidateCodeStr;
      tool.version += 1;
      return { accepted: true, newVersion: tool.version, output: fixedOut };
    } catch (err) {
      return { accepted: false, reason: `COUNTEREXAMPLE_FAILED: ${err.message}` };
    }
  }
}

/**
 * 5. Каузальная оценка WC-LCB-DR-OPE со взвешиванием ковариатного сдвига, ретро-аудитом Y_ext,
 *    двойственной лагранжевой адаптацией цен ресурсов, калиброванным CUSUM и парным CRN-SPSA.
 */
export function applyRetroactiveAuditCorrection(oldDeltaU, tdWeight, rMax, yExtActual, qSemOld) {
  return oldDeltaU + tdWeight * rMax * (yExtActual - qSemOld);
}

export function computeWeightedConformalDoublyRobustUtility(
  observations,
  calibrationResiduals = [],
  wMax = 10.0,
  xiOod = 1.0,
  alphaConf = 0.1,
  gammaRbf = 2.0
) {
  if (!observations.length) return 0.0;
  let sum = 0;

  for (const obs of observations) {
    const rHat = obs.criticPrediction ?? 0.0;
    const executed = obs.wasExecuted ? 1.0 : 0.0;

    let qConf = obs.conformalQuantile ?? 0.0;
    if (!obs.wasExecuted && calibrationResiduals.length > 0 && obs.sqDistToCalib) {
      const weighted = calibrationResiduals
        .map((r, idx) => ({
          r,
          w: Math.exp(-gammaRbf * (obs.sqDistToCalib[idx] ?? 0.0))
        }))
        .sort((a, b) => a.r - b.r);
      const totalW = weighted.reduce((acc, item) => acc + item.w, 0) + 1e-9;
      let cumW = 0;
      for (const item of weighted) {
        cumW += item.w / totalW;
        if (cumW >= 1.0 - alphaConf) {
          qConf = item.r;
          break;
        }
      }
    }

    const oodPenalty = (1.0 - executed) * xiOod * qConf;
    const weight = Math.min(wMax, executed / Math.max(1e-4, obs.propensityScore ?? 1.0));
    const actualDeltaU = obs.retroCorrectedDeltaU ?? obs.actualDeltaU ?? 0.0;
    sum += rHat - oodPenalty + weight * (actualDeltaU - rHat);
  }
  return sum / observations.length;
}

export function updateLagrangianResourcePrices(prevDuals, currentUsage, targetBudgets, etaDual = 0.05) {
  const nextDuals = {};
  for (const key of Object.keys(targetBudgets)) {
    const prev = prevDuals[key] ?? 0.0;
    const diff = (currentUsage[key] ?? 0.0) - targetBudgets[key];
    nextDuals[key] = Math.max(0.0, prev + etaDual * diff);
  }
  return nextDuals;
}

export function selectModelTierForNode(tierStats, epsilonTier = 0.02, tokenShadowPrice = 1.0) {
  const frontierPass = tierStats.frontier?.passRate ?? 0.98;
  const effectiveTolerance = Math.min(0.08, epsilonTier * Math.max(1.0, tokenShadowPrice));
  const threshold = frontierPass - effectiveTolerance;
  if ((tierStats.local_slm?.lcbPassRate ?? 0) >= threshold) return 'local_slm';
  if ((tierStats.light?.lcbPassRate ?? 0) >= threshold) return 'light';
  return 'frontier';
}

export function updateCusumDiscountFactor(
  prevCusum,
  isSuccess,
  p0 = 0.85,
  nu = 0.05,
  threshold = 3.5,
  lambda = 0.4,
  criticEce = 0.02,
  epsilonCritic = 0.08
) {
  const wCal = Math.max(0.0, Math.min(1.0, 1.0 - criticEce / epsilonCritic));
  const residual = wCal * (p0 - (isSuccess ? 1.0 : 0.0));
  const nextCusum = Math.max(0, prevCusum + residual - nu);
  const discount = Math.exp(-lambda * Math.max(0, nextCusum - threshold));
  return { cusumStat: nextCusum, discountFactor: discount, calibrationWeight: wCal };
}

export function computePairedCrnSpsaStep(
  currentPsi,
  prevMomentum,
  pairedOutcomesPlus,
  pairedOutcomesMinus,
  deltaVec,
  cStep = 0.05,
  etaMeta = 0.05,
  betaMom = 0.9,
  bounds = {}
) {
  const n = Math.max(1, pairedOutcomesPlus.length);
  let avgDiff = 0;
  for (let i = 0; i < n; i++) {
    avgDiff += (pairedOutcomesPlus[i] - pairedOutcomesMinus[i]) / (2 * cStep);
  }
  avgDiff /= n;

  const nextMomentum = {};
  const nextPsi = {};
  for (const key of Object.keys(currentPsi)) {
    const gradComp = avgDiff / (deltaVec[key] || 1);
    const m = betaMom * (prevMomentum[key] ?? 0) + (1 - betaMom) * gradComp;
    nextMomentum[key] = m;
    const raw = currentPsi[key] + etaMeta * m;
    const [low, high] = bounds[key] || [-Infinity, Infinity];
    nextPsi[key] = Math.min(high, Math.max(low, raw));
  }
  return { nextPsi, nextMomentum };
}

/**
 * 6. Исполняемый рантайм-оркестратор SpectraRuntime (Fast Loop + Deadlock Detector +
 *    Slow Loop Recovery с реляционным заземлением Psi_adapt + Saga Rollback + Consolidation Sleep).
 *    Позволяет запускать прототип «из коробки» как в in-memory режиме, так и поверх PostgreSQL.
 */
export class SpectraRuntime {
  constructor({
    graph,
    toolRegistry = new ToolRegistry(),
    verifier = new GraphDeterminismVerifier(),
    ontology = new StateOntologyManager(),
    system1Evaluator = null,
    system2Synthesizer = null,
    config = {}
  }) {
    this.graph = graph;
    this.toolRegistry = toolRegistry;
    this.verifier = verifier;
    this.ontology = ontology;
    this.maxSteps = config.hardStepLimit ?? 50;
    this.loopThreshold = config.stateHashLoopThreshold ?? 2;
    this.precedentMemory = []; // In-memory или pgvector адаптер

    // Дефолтный System-1 гейт (совместим с @receptron/laya)
    this.system1Evaluator =
      system1Evaluator ||
      (async () => ({
        driftRisk: 0.12,
        coherence: 0.88,
        approveProb: 0.91,
        rollbackAction: 'keep'
      }));

    // Дефолтный System-2 синтезатор мутаций
    this.system2Synthesizer =
      system2Synthesizer ||
      (async (deadlockCtx) => ({
        operator: 'addEdge',
        from: deadlockCtx.nodeId,
        to: Array.from(this.graph.goalNodes)[0],
        guardFn: () => true,
        priority: 99
      }));
  }

  _hashNodeState(nodeId, state) {
    return crypto
      .createHash('sha256')
      .update(JSON.stringify({ nodeId, state }))
      .digest('hex');
  }

  /**
   * Определение 11: Реляционное заземление прецедента Psi_adapt внутри каузального одеяла Маркова.
   */
  findRelationallyGroundedPrecedent(deadlockType, centerNodeId) {
    const blanket = this.graph.getCausalMarkovBlanket(centerNodeId);
    let bestCandidate = null;
    let bestScore = 0;

    for (const prec of this.precedentMemory) {
      if (prec.deadlockType !== deadlockType || prec.isAntipattern) continue;
      for (const candidateNodeId of blanket.keys()) {
        const node = this.graph.nodes.get(candidateNodeId);
        if (!node) continue;
        const rSet = new Set(node.reads.map((k) => this.ontology.findCanonical(k)));
        const wSet = new Set(node.writes.map((k) => this.ontology.findCanonical(k)));
        const anchorR = new Set((prec.anchorReads || []).map((k) => this.ontology.findCanonical(k)));
        const anchorW = new Set((prec.anchorWrites || []).map((k) => this.ontology.findCanonical(k)));

        const interR = [...rSet].filter((x) => anchorR.has(x)).length;
        const unionR = new Set([...rSet, ...anchorR]).size || 1;
        const interW = [...wSet].filter((x) => anchorW.has(x)).length;
        const unionW = new Set([...wSet, ...anchorW]).size || 1;

        const jaccard = 0.5 * (interR / unionR) + 0.5 * (interW / unionW);
        if (jaccard >= 0.8 && jaccard > bestScore) {
          bestScore = jaccard;
          bestCandidate = { precedent: prec, targetNodeId: candidateNodeId, jaccard };
        }
      }
    }
    return bestCandidate;
  }

  /**
   * Определение 2: Откат состояния назад с вызовом Saga-компенсаторов до последнего барьера необратимости.
   */
  rollbackTrajectory(trajectory, currentState, stepsBack = 1) {
    let stateCursor = structuredClone(currentState);
    const minIdx = Math.max(0, trajectory.length - stepsBack);

    for (let i = trajectory.length - 1; i >= minIdx; i--) {
      const stepEntry = trajectory[i];
      const node = this.graph.nodes.get(stepEntry.nodeId);
      if (node?.hasBarrier) break; // Барьер необратимости Barrier(v) = 1
      if (node?.type === 'tool' && node.idempotency === 'non_idempotent') {
        const tool = this.toolRegistry.tools.get(node.config?.toolId || node.id);
        if (tool?.sagaCompensatorCode) {
          stateCursor = this.toolRegistry.executeSandboxed(tool.sagaCompensatorCode, stateCursor);
        }
      } else {
        stateCursor = structuredClone(stepEntry.stateBefore);
      }
    }
    return stateCursor;
  }

  /**
   * Главный исполнительный цикл сессии (Fast Loop <-> Slow Loop).
   */
  async runSession(initialState = {}) {
    let state = structuredClone(initialState);
    let currentNodeId = this.graph.startNode;
    const trajectory = [];
    const stateHashCounts = new Map();
    const appliedMutations = [];
    let rollbacksCount = 0;

    for (let step = 0; step < this.maxSteps; step++) {
      if (this.graph.goalNodes.has(currentNodeId)) {
        const ver = this.verifier.verify(this.graph);
        return {
          goalReached: true,
          steps: step,
          rollbacksCount,
          finalState: state,
          omegaPenalty: ver.omegaPenalty,
          appliedMutations
        };
      }

      const h = this._hashNodeState(currentNodeId, state);
      stateHashCounts.set(h, (stateHashCounts.get(h) || 0) + 1);

      let deadlock = null;
      if (stateHashCounts.get(h) >= this.loopThreshold) {
        deadlock = { type: 'STATE_HASH_LOOP', nodeId: currentNodeId };
      }

      const node = this.graph.nodes.get(currentNodeId);
      const stateBefore = structuredClone(state);

      if (!deadlock && node) {
        try {
          if (node.type === 'check' && typeof node.config?.assertFn === 'function') {
            if (!node.config.assertFn(state)) {
              deadlock = { type: 'CHECK_FAILED', nodeId: currentNodeId };
            }
          } else if (node.type === 'tool') {
            const toolId = node.config?.toolId || node.id;
            const tool = this.toolRegistry.tools.get(toolId);
            if (tool?.sourceCode) {
              state = this.toolRegistry.executeSandboxed(tool.sourceCode, state);
            } else if (typeof node.config?.handler === 'function') {
              state = await node.config.handler(state);
            }
          } else if (node.type === 'llm' && typeof node.config?.llmHandler === 'function') {
            state = await node.config.llmHandler(state, node.modelTier);
          }
        } catch (err) {
          deadlock = { type: 'TOOL_EXECUTION_ERROR', nodeId: currentNodeId, error: err.message };
        }
      }

      trajectory.push({ step, nodeId: currentNodeId, stateBefore, stateAfter: structuredClone(state) });

      if (!deadlock) {
        const outgoing = this.graph.edges.get(currentNodeId) || [];
        const activeEdges = outgoing.filter((e) => {
          try {
            return Boolean(e.guard(state));
          } catch {
            return false;
          }
        });

        if (activeEdges.length === 0) {
          deadlock = { type: 'NO_VALID_TRANSITION', nodeId: currentNodeId };
        } else {
          currentNodeId = activeEdges[0].to; // Ребра уже отсортированы по приоритету Pi(e)
          continue;
        }
      }

      // Активация Контура 2: Slow Loop Recovery
      const grounded = this.findRelationallyGroundedPrecedent(deadlock.type, currentNodeId);
      const mutationPlan = grounded
        ? { ...grounded.precedent.mutationPlan, from: grounded.targetNodeId }
        : await this.system2Synthesizer(deadlock, state, this.graph);

      const s1Verdict = await this.system1Evaluator(deadlock, mutationPlan);
      if (s1Verdict.approveProb < 0.7 || s1Verdict.driftRisk > 0.35) {
        state = this.rollbackTrajectory(trajectory, state, 1);
        rollbacksCount++;
        continue;
      }

      const candidateGraph = this.graph.clone();
      if (mutationPlan.operator === 'addEdge') {
        candidateGraph.addEdge(
          mutationPlan.from,
          mutationPlan.to,
          mutationPlan.guardFn || (() => true),
          mutationPlan.priority ?? 50
        );
      } else if (mutationPlan.operator === 'addNodeAndBridge') {
        candidateGraph.addNode(mutationPlan.node);
        candidateGraph.addEdge(mutationPlan.from, mutationPlan.node.id, () => true, 1);
        candidateGraph.addEdge(mutationPlan.node.id, mutationPlan.to, () => true, 1);
      }

      // Канал 1: Статический гейткипер детерминизма и транзитивной выполнимости путей
      const checkResult = this.verifier.verify(candidateGraph);
      if (checkResult.status === 'PASS') {
        this.graph = candidateGraph;
        appliedMutations.push({ deadlock, mutationPlan, omegaPenalty: checkResult.omegaPenalty });
        this.precedentMemory.push({
          deadlockType: deadlock.type,
          anchorReads: node?.reads || [],
          anchorWrites: node?.writes || [],
          mutationPlan,
          isAntipattern: false
        });
      } else {
        state = this.rollbackTrajectory(trajectory, state, 1);
        rollbacksCount++;
      }
    }

    return {
      goalReached: false,
      reason: 'HARD_LIMIT_EXCEEDED',
      steps: this.maxSteps,
      rollbacksCount,
      finalState: state,
      appliedMutations
    };
  }
}
```
